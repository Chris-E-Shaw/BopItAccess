Bop It Access 1.0 uses these third-party runtime libraries:

0Harmony.dll - Harmony patching library supplied by the separately installed
MelonLoader. Bop It Access uses it to observe when the game's settings finish
loading on the first mod run. The source and local install packages do not
include this DLL; consult the notices supplied with MelonLoader.

prism.dll — Prism screen-reader and text-to-speech abstraction library by
Ethan Dupuy and contributors. The current Windows x64 mod uses Prism for
speech and braille output.
Project and source: https://github.com/ethindp/prism
License: Mozilla Public License, version 2.0.
License text: https://github.com/ethindp/prism/blob/master/LICENSE

This source repository includes no native Prism DLL.
It also includes no compiled Bop It Access DLL.
Builders must separately obtain or build a compatible Windows x64 prism.dll.
Bop It Access loads Prism dynamically at runtime.

Earlier mod versions used Tolk.dll and nvdaControllerClient64.dll. Previously
prepared local install packages contained those DLLs and their applicable
license texts. Those packages are not GitHub releases and are not part of this
source repository. The current mod no longer requires those DLLs.

Translation authoring tools (not needed or bundled at game runtime):

Argos Translate and its language models were used offline to prepare draft
translations of the mod's speech catalog and project documents. The upstream
project is dual-licensed under MIT or CC0; its model packages are offered under
the same terms. Project: https://github.com/argosopentech/argos-translate
MIT license: https://github.com/argosopentech/argos-translate/blob/master/LICENSE

Google Translate was used, with the project owner's approval, to improve the
machine-translated drafts. Translation requests happened during authoring;
the mod does not contact Google or require an internet connection at runtime.

Beautiful Soup 4 was used to preserve HTML structure while preparing the
translated guides. It is MIT-licensed and is not part of the mod runtime.
Project and license information: https://www.crummy.com/software/BeautifulSoup/
