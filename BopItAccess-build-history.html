Bop It Access: technical build history

A chronological record of 54 mod builds, from v0.1.0 through v0.9.7, plus standalone installer previews. Each entry has a scoped change summary and implementation details. The public GitHub repository contains source code, with no GitHub Releases yet.

Git provenance: Git was introduced after v0.6.12. The 37 source commits were reconstructed from preserved source ZIPs; their Git dates describe the import, not the original build events. Christopher Shaw is the commit author. The co-author trailers reflect verified model records for the corresponding build work: GPT-6 Luna for the first build and GPT-6 Sol for the remaining 36. Local install packages and version tags are not part of the initial GitHub publication.
