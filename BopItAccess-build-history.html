Bop It Access: technical build history

A chronological record of all 37 released builds, from v0.1.0 through v0.6.12. Each entry is written like a GitHub commit: a scoped subject, implementation details, and links to the preserved release archives.

Git provenance: Git was introduced after v0.6.12. The v0.1.0–v0.6.12 commits and tags were reconstructed from preserved source ZIPs; their commit authors and dates describe the import, not the original release events. These entries summarize the build contents without inventing historical metadata. The source and install archive links below point to files in this local workspace; Git tags independently preserve each source snapshot.

Foundation: v0.1.0–v0.4.0

v0.1.0feat

feat(core): initialize Tolk speech output

  • Load the MelonLoader mod, initialize Tolk on a background thread, enable its SAPI fallback, and announce “Bop It Access Ready” at startup.
  • Package the Tolk and NVDA bridge binaries with their license notices. This prototype does not read menus yet.

Source snapshot · Install package

v0.2.0feat

feat(menu): announce focused main-menu buttons

  • Observe Unity’s selected native button and speak the six main-menu labels when focus changes.
  • Route focus announcements through a dedicated speech worker; build against the game’s generated IL2CPP assemblies under .NET 6.

Source snapshot · Install package

v0.3.0feat

feat(settings): speak focused options and changed values

  • Read native Settings rows, including the conditional Go Online action. On focus, announce the option with its displayed value.
  • When a slider or toggle changes without moving focus, speak only the new value.

Source snapshot · Install package

v0.4.0feat

feat(settings): read Controls and Audio Calibration

  • Add Controls.cs readers for focused bindings, binding changes, rebinding feedback, and Reset to Default.
  • Add Calibration.cs speech for available controls, calibration stages, the warmup countdown, and displayed latency while avoiding the timed beat cues.
  • Suppress the game’s meaningless trailing zero on the Audio Latency and Controls action rows.

Gameplay and configuration: v0.5.0–v0.5.19

v0.5.0feat

feat(play): read mode and song-selection screens

  • PlayModes.cs announces Solo, Party, Pass It, and One on One focus.
  • TrackSelect.cs reads the selected Shapes, Space, City, or Office theme, Extreme state, and Twist/Pull/Bop/Back instructions; later changes speak only the changed theme or difficulty.

Source snapshot · Install package

v0.5.1feat · fix

feat(results): prioritize final scores; repeat song-select introduction

  • GameOver.cs reads Solo, Party, and Pass It scores, the One-on-One winner, focused result actions, and fresh rank/high-score data. ResultRank.cs avoids stale leaderboard updates.
  • Dispatch the automatic result before the focused result-menu item so menu speech cannot interrupt the score.
  • Track song-select panel visits so the complete introduction is spoken whenever that screen opens, not only on the first visit.

Source snapshot · Install package

v0.5.2feat

feat(content): read leaderboards, achievements, and credits

  • Leaderboards.cs reads filters, score rows, empty/loading states, and Party name/result states; Page Up and Page Down browse rows without changing visual selection.
  • Achievements.cs reads book pages, descriptions, and lock state. Credits.cs supports line-by-line reading with visual-scroll and whole-text fallbacks.
  • Add sequential speech queuing for content that should follow earlier announcements.

Source snapshot · Install package

v0.5.3fix

fix(content): constrain leaderboard and book speech to visible states

  • Require game-over state and a visible leaderboard parent before reading result leaderboards, preventing ghost announcements on mode and song selection.
  • Speak leaderboard group/date filter changes first, then queue score rows. Distinguish the closed achievements cover from open pages; announce instructions on opening and closure only after an actual exit.
  • Hold focus briefly after book closure while its page content and main-menu selection settle.

Source snapshot · Install package

v0.5.4feat · preview

feat(controls): preview leaderboard filter binding rows

  • Add scrollable Group Previous/Next and Date Previous/Next rows to Controls for the native one-dimensional leaderboard composites. Defaults are O/P and K/L on keyboard, bumpers and D-pad left/right on controller.
  • The initial implementation cloned native ControlRow listeners and used a Harmony hook to choose the native binding part. Rebinding was subsequently repaired in v0.5.5.

Source snapshot · Install package

v0.5.5fix

fix(controls): isolate added-row rebinding from native listeners

  • Remove the global Harmony rebinding hook and cloned native ControlRow listeners that caused crashes, including when changing existing game controls.
  • Use independent Input System interactive rebinding for the four added rows while retaining native-style prompts, focus, scrolling, and reset snapshots.

  • Add an Off-by-default Trim Silence toggle and a SAPI path that captures 22,050 Hz, 16-bit mono PCM in memory, removes near-silent leading/trailing samples with padding, then plays the result.
  • Handle interrupted capture, direct-output fallback, and automatic result-score protection through rendering and playback. The path could delay long utterances while rendering.

  • Apply the filter at the shared output boundary so Tolk, direct NVDA, SAPI, and braille receive the same processed text.
  • Cache separate-braille capability checks for one second and log slow SAPI setup/Speak/braille dispatch stages. These logs do not measure audible onset.
