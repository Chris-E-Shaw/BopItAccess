Bop It Access : historique de construction technique

Un enregistrement chronologique de 58 builds du mod, de v0.1.0 à v0.9.11, accompagné de préversions autonomes de l’installeur. Chaque entrée comporte un résumé des modifications étendues et des détails de mise en œuvre. Le référentiel public GitHub contient du code source, sans téléchargements compilés ni versions GitHub pour le moment.

Provenance Git : Git a été introduit après la v0.6.12. Les 37 commits sources ont été reconstruits à partir de ZIP sources préservés ; leurs dates Git décrivent l'importation, pas les événements de construction d'origine. Christopher Shaw est l'auteur du commit. Les bandes-annonces des co-auteurs reflètent les enregistrements de modèle vérifiés pour le travail de build correspondant : GPT-6 Luna pour la première build et GPT-6 Sol pour les 36 restants. Les packages d'installation locaux et les balises de version ne font pas partie de la publication initiale GitHub.
