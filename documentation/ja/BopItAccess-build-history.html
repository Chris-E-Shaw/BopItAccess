Bop It Access: 技術的なビルド履歴

v0.1.0 から v0.9.2 までの 49 ビルドの時系列レコード。各エントリには、範囲を限定した変更の概要と実装の詳細が含まれます。パブリック GitHub リポジトリにはソース コードが含まれていますが、コンパイルされたダウンロードや GitHub リリースはまだありません。

Git の出所: Git は v0.6.12 以降に導入されました。 37 個のソース コミットは、保存されたソース ZIP から再構築されました。 Git の日付は、元のビルド イベントではなく、インポートについて説明しています。 Christopher Shaw がコミットの作成者です。共同作成者のトレーラーには、対応するビルド作業の検証済みモデル レコードが反映されています。最初のビルドは GPT-6 Luna、残りの 36 は GPT-6 Sol です。ローカル インストール パッケージとバージョン タグは、最初の公開版 GitHub の一部ではありません。

  • コントローラーの十字キーとキーボードによるメニュー移動の入力イベント、選択中の項目、そして2フレーム以内にフォーカスが変わったかをログに記録します。読み上げログと照合して、上下の入力が反応しないという報告を調べます。
  • メニュー操作と読み上げの動作は変更しません。テスト中に入力の取りこぼしが再発した場合、ログを原因の特定に役立てます。

v0.9.2feat · docs

feat(音声): OneCore 音声設定と出力方式に応じたメニュー表示

  • 自動モードでは、実行中のスクリーンリーダー、OneCore、SAPI の順に選びます。出力モードの一覧でも OneCore を SAPI より前に配置し、手動選択と利用できない場合の代替動作を維持します。
  • 音声、音量、速度、ピッチの4項目は、実際に動作している Prism の出力方式に合わせて切り替わります。項目名は OneCore または SAPI と表示し、これらの設定に対応しない出力方式では非表示にします。
  • Prism から OneCore の音声を名前と言語付きで取得します。OneCore と SAPI の設定は、それぞれのシステム既定の音声を含めて別々に保存し、現在の出力方式に対応する設定を適用します。
