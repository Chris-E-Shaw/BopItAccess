Bop It!とは？

Bop It! The Video Game Bop It のリズムとリアクション ゲームをコンピューターにもたらします。音声でコマンドが呼び出され、時間切れになる前に対応する入力を行います。難易度クラシックの主なコマンドは次のとおりです。 叩く, ねじる、そして 引く。極端な難易度も追加されます 回す そして はじく。コマンドは速くなるため、ラウンドが進むにつれて聞き取りとタイミングがより重要になります。このゲームでは、ソロ、パーティー、パス イット、および 1 対 1 のプレイが提供され、シェイプ、スペース、シティ、オフィスの 4 つのビジュアルおよび音楽ステージが用意されています。の 公式Steamページ ゲームの紹介と、 公式ゲーム説明 そのモードを説明します。

コマンドが聞こえたら、それに割り当てられたコントロールを使用します。たとえば、デフォルトのキーボードでは、叩く はスペースです。すべてのデフォルトは次の場所にあります。 コントロールリファレンス。開始する前にすべてを暗記する必要はありません。MOD はメニュー上のボタンのヒントを読み上げることができ、オンデマンドでヒントをリクエストすることもできます。

Bop It Accessとは？

Bop It Access は、 Windows x64 Steam バージョン ゲームの。 MOD は、ゲームの動作を変更するオプションの追加です。これには、メニューと結果に対する音声と点字のサポート、4 つのステージのオンデマンド説明、追加のコントロール、フレーム レート制限などの便利な設定が追加されています。音声によるゲームプレイの合図とタイミングをそのままにしながら、ゲームの操作を容易にすることを目的としています。

この MOD は、ゲームにロードするために MelonLoader を使用します。 Tolk を使用してサポートされているスクリーン リーダーと通信し、Windows SAPI 音声をフォールバックとして使用できます。ゲームを置き換えるものではないため、独自の Bop It! のコピーが必要です。

この MOD は、メニューとアナウンスに関してゲームの言語設定に従います。英語、フランス語、イタリア語、ドイツ語、スペイン語 (スペイン)、スペイン語 (ラテンアメリカ)、日本語、韓国語、中国語 (簡体字)、ポルトガル語 (ブラジル) が含まれます。

制作について正直にお伝えすること

この MOD は人工知能との多大な協力のもとに作成されました。 MOD のリサーチはすべて AI によって行われ、そのコードは元々手作業で書かれたものではなく、AI によって生成されました。デザインの決定とゲームプレイのテストは完全に人間によるものでした。以前の追加と変更はすべて人によって慎重にレビューされ、実際の人々がさまざまなシステムで MOD をプレイしてテストしました。新しい多言語テキストは機械翻訳で作成されており、流暢な話者によるレビューがまだ必要です。エージェント コーディングがなければ、このプロジェクトは存在しません。この人間主導、AI 支援のプロジェクトにチャンスを与えていただきありがとうございます。

注意事項と制限

  • ラウンド前に説明が求められます。 この MOD は、アクティブなゲームプレイ中に意図的に風景をナレーションしません。プレイヤーはゲームの口頭コマンドを聞いて反応する必要があります。追加のナレーションがコマンドをカバーし、ラウンドを終了する可能性があります。
  • SAPI はバックアップ音声エンジンです。 これは、必要な場合、またはサポートされているスクリーン リーダーが実行されていない場合に使用できますが、その応答性はまだこのプロジェクトの目標を下回っています。インストールされている音声とシステムが遅延に影響を与える可能性があります。英語以外の音声の場合は、選択したゲーム言語をサポートするインストール済みの SAPI 音声を選択します。 MOD は追加の音声をインストールしません。
  • 一部のネイティブ コントロールはまだ修正されています。 この MOD はゲームの [コントロール] メニューを大幅に拡張しますが、すべてのゲーム入力を再マップ可能にするわけではありません。
  • フレーム レートは入力ポーリングに影響します。 FPS リミッターによりシステム負荷を大幅に軽減できます。アニメーションを意図的に遅くしたり、ゲームのタイミングを変更したりすることはありませんが、FPS が低い場合、ゲームはフレームベースの入力をチェックする頻度が低くなります。設定を高くすると、特に高速ラウンドの場合、より正確な入力タイミングが得られます。
  • 音声サポートはメニューと結果において最強です。 予期しないパネル上で、MOD は表示されているテキストとフォーカスされたコントロールを見つけると、それを読み取ることができます。マウスホバーは、そのアイテムが実際にゲームフォーカスを取得するまで音声を発しない場合があります。
  • Windows x64 が現在の MOD プラットフォームです。 ゲームは他のシステム向けに販売されている可能性がありますが、この MOD の現在の読み込みと音声依存関係は Windows x64 向けです。
  • 翻訳にはレビューが必要です。 英語以外の初期の MOD テキストとガイドは機械翻訳されました。一部の言葉遣い、ゲーム用語、入力名については、流暢な話者による修正が必要な場合があります。不明瞭な点や不正確な点がある場合はご報告ください。

ゲームの購入と動作環境の確認

購入する Bop It! The Video Game に Steam。 Steam が初めての方は、 Steamをインストールしてください、アカウントを作成またはサインインし、ストア ページからゲームを購入し、Steam ライブラリからインストールします。の Steam スタート ガイド それらの手順について説明します。ゲームの購入はこの MOD とは別に行われます。

ご購入・お取り付けの前に必ずご確認ください。 現在の最小システム要件は Steam ページに記載されています。このガイドの作成時点では、Windows の最小構成には、Windows 10 64 ビット、Intel i5-4460 または AMD FX-6300、8 GB のメモリ、2 GB のビデオ メモリを備えたグラフィック プロセッサ、および 2 GB のストレージが含まれていました。このページには、リーダーボードにはインターネット接続が必要であるとも記載されています。要件は変更される可能性があるため、Steam のリストが最終的な参照となります。

ゲームの最小要件を満たしていないコンピューターでも問題を試して報告することは歓迎されます。ただし、仕様不足のシステムによって問題が発生した場合、修正は保証されません。

Modの入手とインストール

インストーラーのステータス: パブリック MOD インストーラーはまだ設計またはリリースされていないため、実際のインストーラーのダウンロード リンクやインストーラー画面はありません。ぜひご覧ください Bop It Access プロジェクトページ 将来の可用性のために。これはインストーラー リンクの意図されたホームであり、インストーラーが現在そこにあるという主張ではありません。

現在のインストール ルート: ソースからビルド

現在、パブリック GitHub リポジトリにはソースとドキュメントが含まれていますが、コンパイルされたダウンロードや GitHub リリースはありません。ビルドとは、ソース ファイルを MOD の DLL に変換することを意味します。の リポジトリのビルド手順 は維持されている参照です。現在の完全なルートを日常の言葉で表すと次のようになります。

  1. Windows x64 の Steam を通じてゲームをインストールします。デフォルトの場所を使用しなかった場合は、Steam のライブラリからフォルダーを見つけます。
  2. 試合が終了したことで、 MelonLoaderをインストールしてください そのゲームフォルダーに。開発はこのゲームで x64 MelonLoader 0.7.3 オープンベータ版を使用しました。他の組み合わせはまだ検証されていません。一度ゲームを起動し、再度終了してください。これにより、MelonLoader は MOD に必要なファイルを準備できます。
  3. .NET 6 ターゲティング パックを含む .NET SDK をインストールします。 Bop It Access ソースをダウンロードまたはクローンします、そのファイルが含まれるフォルダー内の PowerShell を開きます。 README.mdをクリックし、以下のコマンドを実行します。 Steam ライブラリが別の場所にある場合は、サンプル ゲームのパスを変更します。
$gameDir = 'C:\Program Files (x86)\Steam\steamapps\common\Bop It!'
dotnet build .\src\BopItAccess.csproj -c Release "-p:BopItGameDir=$gameDir"
  1. ゲームを閉じた状態で、ビルドしたファイルをコピーします src\bin\Release\net6.0\BopItAccess.dll ゲームの中へ Mods フォルダ。必要に応じてそのフォルダーを作成します。ビルドをコピーする src\bin\Release\net6.0\documentation フォルダもゲームフォルダに入れます。このガイドには、このガイドとそのリンクに必要な付属文書が含まれています。
  2. 互換性のある 64 ビットを入手する Tolk.dll そして nvdaControllerClient64.dll で説明されているように、上流のソースから リポジトリのインストール手順。両方をメイン ゲーム フォルダー内のゲームの実行可能ファイルの横に配置します。 そうではない 内側 Mods.
  3. スクリーン リーダーを使用している場合は開始し、Steam を通じてゲームを起動します。互換性のある実行中のスクリーン リーダーがない場合、MOD は SAPI 音声を使用できます。

Steam の一般的な場所の 1 つは次のとおりです。 C:\Program Files (x86)\Steam\steamapps\common\Bop It!。別の Steam ライブラリを選択した場合、場所が異なる場合があります。プロジェクトからローカルに提供されたインストール ZIP がある場合は、ゲームを閉じて、そのコンテンツをゲーム フォルダーに抽出します。 Mods 結合するフォルダー。これらのローカル パッケージは、ソースのみの GitHub リポジトリとは別のものです。

初めて起動するとき

  1. スクリーン リーダーを使用している場合は、スクリーン リーダーを起動します。 MelonLoader、mod DLL、および必要な Tolk ランタイム ファイルをインストールした後、Bop It! から Steam を起動します。
  2. MOD を初めて使用するとき、ゲームの音楽、SFX、およびボイスオーバーのボリュームは 30 から始まります。アップグレードしている場合、保存されたゲームのオーディオ レベルはそのまま残ります。
  3. 発表を待ちます: Bop It Access スピーチの準備ができました。ゲームはまだロード中です。コントロールを使用する前に、タイトル画面またはメインメニューのアナウンスを待ってください。 MOD はゲームのロードが完了する前に準備が整います。
  4. タイトル画面のアナウンスまでさらに数秒待ちます。入力はロード中に何も行わない可能性があります。 叩く (デフォルトではスペース、またはコントローラーの決定ボタン) を押してタイトル画面から先に進みます。ようこそ機能を初めて起動すると、メイン メニューの前にようこそ画面が表示されます。 Up/Down で移動し、Enter、Space、またはコントローラーの確定で確定します。
  5. 以前に音声をオフにしている場合、保存された設定はオフのままになります。この MOD は、現在のキーボードとコントローラーの Toggle Speech バインディングを使用して、起動時に音声による回復メッセージを表示します。デフォルトでは、F8 キーを押すかコントローラーの選択を押すと再びオンになります。

各モードの詳しい説明

4 つのモードはすべて、曲/ステージを選択し、クラシックまたはエクストリームを選択することから始まります。ステージでは見るもの、聞くものが変化し、コマンドはどのような入力を行うべきかを指示します。 Classic は、叩く、ねじる、および 引く を要求します。Extreme は、回す および はじく を要求することもできます。ゲームがコマンドを読み上げたら、タイム ウィンドウが終了する前に割り当てられた入力を押します。再生する前に、[設定] > [コントロール] で割り当てを確認または変更できます。実行が成功するとテンポが上がるため、到達するための固定された最後の曲セクションはありません。これらのルールは、 公式ゲーム説明 ゲームの現在のスコアと結果の画面。

ソロ

ソロはリズムを学ぶのに最も簡単な場所です。音声コマンドごとに 1 人が応答します。ゲームに 叩く と表示されている場合は、叩く を入力してください。 ねじる または 引く と表示されている場合は、代わりにその入力を使用してください。 Extreme では、回す と はじく にも備えてください。コマンドが速くなったら続けてください。

採点: 正解するたびに、進行中の実行に 1 ポイントが追加されます。スコアは、成功した応答の数です。応答が間違っていたり、応答が遅れたりすると、その実行は終了します。最終結果画面にはスコアの数値が表示されます。 MOD は、リプレイ、リーダーボード、またはバックを読み取る前にそれをアナウンスします。 「スコアを読む」を押すと、もう一度聞くことができます。ローカル、フレンド、およびグローバル リーダーボード ビューが利用可能な場合、ソロ スコアはこれらのビューにも表示される場合があります。

やり直す方法: 結果画面で [再生] を選択するか、戻って別のモードまたは曲を選択します。リプレイは新しい実行です。以前の結果は、ゲームが記録するリーダーボードで引き続き比較できます。

パーティー

パーティーはグループで順番に参加します。それぞれの人が遊ぶ 自分自身の Solo と同じ種類の呼び出されたコマンドに応答して実行します。人のランが終了すると、ゲームはそのスコアに付ける名前を求めることができます。セッションのパーティー リーダーボードに進み、次の人に順番を渡します。これは、全員が同時に行動することなく実行を比較するためのフレンドリーな方法です。

採点: 成功した応答により、そのプレーヤーの数値的なランスコアが構築されます。間違ったコマンド、失敗したコマンド、または遅れたコマンドによりランが終了し、最終スコアはそのプレーヤーのものとなります。セッション リーダーボードには名前、ランク、スコアがリストされるため、グループは結果を比較できます。ゲームは正式な勝者を 1 人に課すものではありません。あなたのグループは何が勝利としてカウントされるかを決定できます。 MOD はゲームオーバー時にスコアを読み取り、次に選択したメニューを読み上げ、パーティー名とリーダーボードのステップを読み上げます。

プレイを続ける方法: 提示されたら「続行」を使用し、プロンプトが表示されたら名前を選択または確認し、ゲームに従って次のプレーヤーまたはスコア ビューを表示します。リプレイすると、終了したランを延長するのではなく、別の得点されたランが始まります。

バトンタッチ

バトンタッチは、みんなで一つの記録に挑戦するモードです。ゲームがバトンタッチ！と指示するまで、まず一人がコマンドに応えます。その指示が聞こえたら、すみやかに次の人へコントローラーを渡してください。次のプレイヤーは同じ連続記録を引き継ぎます。以後もゲームの指示に従ってコントローラーを渡し、コマンドに応え続けます。誰に渡すかを先に決め、安全に受け渡せる場所で遊びましょう。

採点: 正解すると、各人に新しいスコアが開始されるのではなく、1 つの共有数値スコアが継続されます。コマンドをミスして連続記録を破った人がラウンドを終了します。結果画面には最終的な共有スコアが表示されます。MOD は自動的に読み上げ、スコアの読み取りで繰り返すことができます。スコアはグループがどこまで到達したかを示します。このモードでは、個々のプレイヤーのランキングではありません。

再試行する方法: 新しい共有ストリークを開始するには [再生] を選択し、結果を残すには [戻る] を選択します。

1対1

1 対 1 では 2 人のプレイヤーが参加し、 黄色 そして 緑、同じラウンドに入る。それぞれはから始まります 三つの人生。黄色は ねじる および 引く に応答します。緑は 回す と はじく に応答します。 叩く は共有レースです。両方のプレイヤーが準備を整えている必要があり、最初に 叩く をヒットした人が、ゲームの 3 ライフ制限までライフを獲得します。ゲームでは、いくつかの変更に対して微妙なサウンドが提供されます。 [設定] > [MOD 設定] > [1 対 1 フィードバック] がオン (デフォルト) の場合、MOD はアクティブな色の開始または変更、および損失または利益後のライフの数を通知します。

ラウンドの終了方法: 必要なコマンドをミスすると、責任のあるプレイヤーは命を落とします。最初にライフがゼロになったプレイヤーが負けとなり、他の色のプレイヤーが勝ちとなります。 Solo、Party、Pass It とは異なり、結果は 勝者、最終スコアの数値ではない。 MOD はゲームオーバー時に勝利の色を発表します。 Read Score は、結果画面が表示されている間、その結果を繰り返します。オプションのライフアナウンスはこのモード専用です。

一緒に準備をしましょう: 始める前に、どちらが黄色でどちらが緑色であるかに同意してください。 1 つの入力デバイスを共有する場合は、現在のコントロール画面、特に 2 番目の 叩く の割り当てを確認してください。 1 対 1 は速いので、練習ラウンドは両方のプレーヤーがコントロールを学ぶのに役立ちます。
