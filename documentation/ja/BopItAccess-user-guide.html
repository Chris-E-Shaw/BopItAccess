ようこそ

Bop It Access へようこそ!初めての Bop It ゲームでも、初めてのビデオ ゲームでも、すでに大好きなゲームでも、大歓迎です。このガイドでは基本的なことから始めて、MOD の機能について説明します。上記の内容を使用して、トピックに直接ジャンプできます。

キーボードはコンピューターのキーをまとめたものです。コントローラーは手に持って使うゲームパッドです。このガイドの Xbox ボタン名は一例で、ほかのコントローラーでは同じ位置のボタンに別の名前が付いている場合があります。メニュー項目は「プレイ」や「設定」などの選択肢です。現在選ばれている項目にフォーカスがあり、決定ボタンを押すとその項目が実行されます。

Bop It Accessとは？

Bop It Access は、Steam の Windows x64 版『Bop It!』向けの非公式 MOD です。MOD とは、ゲームの動作を変える追加プログラムのことです。この MOD はメニューや結果の音声・点字出力、4 つのステージの説明を聞く機能、追加の操作方法、フレームレート制限などの設定を提供します。ゲーム本来の音声コマンドとタイミングを保ちながら、操作しやすくすることを目指しています。

この MOD は MelonLoader で読み込まれ、Prism を通じて音声と点字を出力します。ゲーム本体は別途必要です。 Auto は実行中の対応スクリーンリーダーを優先し、次に OneCore、最後に SAPI を使用します。

この MOD は、メニューとアナウンスに関してゲームの言語設定に従います。英語、フランス語、イタリア語、ドイツ語、スペイン語 (スペイン)、スペイン語 (ラテンアメリカ)、日本語、韓国語、中国語 (簡体字)、ポルトガル語 (ブラジル) が含まれます。

注意事項と制限

  • ラウンド前に説明が求められます。 この MOD は、アクティブなゲームプレイ中に意図的に風景をナレーションしません。プレイヤーはゲームの口頭コマンドを聞いて反応する必要があります。追加のナレーションがコマンドをカバーし、ラウンドを終了する可能性があります。
  • ステージの説明には目視による確認が必要です。 4つすべてのステージの説明は、目の見えるユーザーやプレイヤーによって正確さが検証されていません。今後、目視で内容を確認し、正確さを確かめる必要があります。
  • Auto は実行中のスクリーンリーダー、OneCore、SAPI の順に優先します。応答速度はインストール済みの音声やシステムによって変わります。この MOD は音声を追加インストールしません。
  • 一部のネイティブ コントロールはまだ修正されています。 この MOD はゲームの [コントロール] メニューを大幅に拡張しますが、すべてのゲーム入力を再マップ可能にするわけではありません。
  • フレーム レートは入力ポーリングに影響します。 FPS リミッターによりシステム負荷を大幅に軽減できます。アニメーションを意図的に遅くしたり、ゲームのタイミングを変更したりすることはありませんが、FPS が低い場合、ゲームはフレームベースの入力をチェックする頻度が低くなります。設定を高くすると、特に高速ラウンドの場合、より正確な入力タイミングが得られます。
  • Windows x64 が現在の MOD プラットフォームです。 Prism は他のプラットフォームをサポートしているため、将来の開発に役立つ可能性があります。このリリースのゲーム統合、ビルド参照、およびインストール手順は Windows x64 用です。
  • 翻訳にはレビューが必要です。 英語以外の初期の MOD テキストとガイドは機械翻訳されました。一部の言葉遣い、ゲーム用語、入力名については、流暢な話者による修正が必要な場合があります。不明瞭な点や不正確な点がある場合はご報告ください。

提供されたインストーラーを使用する

Bop It! を終了し、BopItAccess-Installer.exe を開いて、Windows の管理者権限の確認を許可します。インストーラーはすべてのドライブの Steam ライブラリからゲームを探します。最初に「Welcome and controls」の説明欄へフォーカスが移ります。Alt+W でこの操作案内に戻れます。表示されたゲームのフォルダーを確認し、必要なら「Browse」で選び直してください。Tab で項目を移動します。Alt+L で変化するステータスログに移り、矢印キーで文章を読み、選択してコピーできます。

インストーラー0.2.8は起動時に短時間だけ最前面表示とキーボードフォーカスを要求します。制限付きの起動確認が終わっても別のウィンドウがアクティブな場合、タイトルとタスクバーのボタンを点滅させ、Alt+Tabでインストーラーへ切り替えるよう案内します。キーボードやコントローラーを使う前にインストーラーをアクティブにしてください。Alt+Gはゲームフォルダー欄にフォーカスを移します。

起動時には Show advanced のチェックが外れています。チェックすると Install alpha、Save diagnostics、Copy diagnostics が表示されます。Install は公開された GitHub リリースがあれば最新版をダウンロードします。現在は公開リリースがないため、テスターは Show advanced を有効にして Install alpha を使ってください。Alpha は確認後に最新のソースをダウンロードし、使用中のコンピューターでビルドします。インストール済みの版より新しい公開リリースが見つかると Update が表示されます。

ステータスメッセージは、何をダウンロード、インストール、完了しているかをわかりやすく説明します。進行状況バーはインストール全体の推定進行度を表し、ダウンロードやファイルごとに最初からやり直しません。5 パーセントポイントずつ進みます。準備中には表示が変わらないまま時間がかかることがあります。新しい更新の通知、診断情報のコピー完了は Windows のアクセシビリティ通知を通してスクリーンリーダーに送られます。実際に読み上げるかは、使用するスクリーンリーダーと Windows 通知への対応によります。

インストーラー 0.2.8 はインストール中に Bop It! を起動しません。Alpha は一致するローカルのビルド用ファイルを再利用するか、ゲームを終了したまま、インストール済みのゲームから一時ファイルを準備します。その後、ゲームフォルダーへ MelonLoader を配置し、すぐに Mods/BopItAccess.dll を追加します。続いて Prism、設定、すべての文書、アンインストール用ファイルを配置します。成功メッセージを待ち、準備ができたら自分で Steam からゲームを起動してください。

インストールが成功すると Play Bop It! The Video Game が表示されます。準備ができたら選んで、自分で Steam を通してゲームを起動できます。インストーラーがインストール中に自動でゲームを起動することはありません。

コンパイル済みのリリースには Windows x64 の .NET 6 ランタイムが必要で、開発用 SDK は不要です。既存の完全なランタイムは再利用します。不足している場合は Microsoft からダウンロードして MelonLoader/Dependencies/dotnet に配置します。Install alpha には対応する .NET SDK と .NET 6 ターゲティングパックも必要です。既存の SDK を再利用するか、Microsoft の公式 SDK をシステム全体にインストールします。ゲームのルートには新しい SDK フォルダーを作りません。MelonLoader 0.7.3 Open-Beta と Prism 0.18.3 は公式リリースから取得します。共有の Microsoft .NET コンポーネントと SDK は中止やアンインストール後も残ります。

Quit はインストーラーを終了します。インストール中なら、閉じる前に中止して変更を元に戻すか確認します。Keep open を選ぶとそのまま続行します。判断している間にインストールが完了すると、ダイアログは完了したことを知らせる内容に変わり、Quit で完了済みのインストールを取り消すことはありません。アンインストールの削除が始まっている場合は、安全に完了してから終了します。Abort も確認を求め、この試行で行ったゲームファイルの変更を元に戻します。Microsoft .NET のセットアップ中に中止した場合は、共有コンポーネントのインストールが安全に終了するまで待ちます。

Uninstall を確認した後、Uninstall for me または Uninstall for everyone を選びます。どちらもこのゲームフォルダーの共有 Mod ファイルを削除するため、そのゲームを使う誰にとっても Mod は利用できなくなります。選択によって変わるのは Windows に保存された Mod 設定の削除対象です。操作を要求した自分のアカウントだけか、サインアウト中のアカウントを含むすべてのローカル Windows プロファイルかを選べます。元のゲームの設定は保持します。.NET SDK もインストール済みのまま残ります。

インストーラー自身が導入した MelonLoader を削除し、他の Mod が必要としていない場合は、既知の Loader.cfg と MelonPreferences.cfg、空の Plugins、UserLibs、UserData フォルダーも削除します。Bop It Access の設定、既知のログ、ガイド、インストーラーのファイルを削除します。他の Mod、以前からある共有ローダーファイル、認識できないファイルは保護します。そのため、未知のファイルがあるとフォルダーが残る場合があります。無関係のデータを消す代わりに、診断情報にそのことを記録します。

アンインストール後もインストーラーは開いたままです。結果を確認し、診断情報を保存したり、再インストールしたりできます。終了する場合は Quit を選んでください。実行中のアンインストール補助ファイルと自動診断ログはウィンドウを閉じた後に削除します。同じウィンドウでの再インストールは新しいインストール記録から始まり、以前の遅延クリーンアップが新しいインストールを削除することはありません。

Windows の「インストールされているアプリ」からも同じ確認、設定の削除対象の選択、クリーンアップを使います。インストーラーはゲームフォルダーに BopItAccess-uninstall.ps1 を配置します。これはインストール済みのアンインストーラーへのショートカットです。今後のソースビルドの出力にも含まれます。スクリプトを手動でコピーするだけではアンインストーラー自体はインストールされません。所有権記録のない古い手動インストールでは、識別できる Mod ファイルだけを削除し、由来を確認できない共有ファイルは残します。

クリーンアップを安全に完了できない場合は理由を知らせ、再試行に必要な情報を保持します。管理対象のインストールでは削除が成功するまで Windows のアンインストール項目と再開地点を残します。古い手動コピーには永続的な所有権記録がありません。その警告は開いているインストーラーで再試行してください。Bop It! の実行中には Mod のインストール、更新、削除を行わないでください。

インストーラーをコントローラーで操作する

Xbox 型のコントローラーと、Windows が XInput を通じて認識する他のコントローラーに対応します。インストーラーの操作は、ゲーム内で割り当て変更できる操作とは別です。D パッドまたは左スティックで項目間を移動します。テキスト欄にフォーカスがある場合は、方向入力でそのテキストを確認します。バンパーは常に前後のフォーカス可能な項目へ移動します。A は選択中のボタンやチェックボックスを操作します。入力を受け付けるのは、このインストーラーまたはそのダイアログが最前面にある間だけです。

B はダイアログで戻る、またはキャンセルします。インストーラーのメインウィンドウでは、インストール中なら中止の確認、それ以外なら Quit と同じ動作になります。Start はメインウィンドウで Quit、ダイアログでは戻る操作です。Y（前面上側のボタン）は、インストーラーのテキスト欄にフォーカスがあるときにすべてのテキストを選択します。メインウィンドウでテキスト欄以外にフォーカスがある場合はShow advancedを切り替えます。状態ログなどインストーラーのテキスト欄では、Dパッドや左スティックが矢印キーと同じように動作します。左／右は文字単位、上／下は行単位で移動します。LTを押すとCtrl相当になり、左／右は単語単位、上／下は段落単位で移動します。RTを押すとShift相当になって選択範囲を広げ、LTとRTを同時に押すと単語や段落を選択します。Xは選択中のテキストだけをコピーするので、先に必要な部分を選択してください。キーボードのCtrl+Cも引き続き選択範囲をコピーします。テキストが選択されていない場合、カーソル位置の文字、単語、行、段落の確認もアクセシビリティ通知で伝えます。コピー成功時にはアクセシビリティ通知で確認し、選択範囲がない場合やコピーに失敗した場合も通知します。読み上げられるかどうかは、スクリーンリーダーのWindows通知への対応に依存します。Windows 標準のフォルダー選択や保存ダイアログのコントローラー操作は、まだ人による確認が必要です。フォルダーやファイル名の入力にはキーボードも使えます。XInput 非対応の機器は今回の実装の対象外です。

独立したWelcome and controls欄にコントローラーのテキスト確認操作が記載されています。Alt+Wで戻り、Alt+Lで変化するStatus logへ移動します。どちらも読み取り専用で、選択と確認が可能です。Show advancedはチェック状態を通知し、すべて選択は成功または空欄を通知します。 キーボードのCtrl+Aですべてのテキストを選択し、Ctrl+Cで選択範囲をコピーします。

Welcome and controls（Alt+W）または Status log（Alt+L）にフォーカスを移すと、短い項目名が使われます。操作説明は Welcome and controls の中でいつでも確認できます。インストーラーのボタンを押すと、すぐにスクリーンリーダーへ通知し、前のインストーラー音声を中断するよう要求します。確認、キャンセル、エラーも引き続き通知します。すべてのステータスメッセージが自動的に読み上げられるわけではありません。通知の読み上げ方は、スクリーンリーダーの Windows 通知への対応によって異なります。

Bop It Access を手動でインストールする

Bop It Access のインストーラーを実行せずに、コンパイル済みの MOD を入れる方法です。購入済みの Windows x64 版ゲーム、MelonLoader 0.7.3 Open-Beta の x64 版、.NET 6 Windows x64 ランタイムが必要です。.NET SDK は不要です。コンパイル済み ZIP には MelonLoader と .NET は含まれません。

MelonLoader · .NET 6 Windows x64 runtime

  1. Steam で Bop It! をインストールします。Steam ライブラリからインストール済みファイルを参照する操作を使い、ゲームのフォルダーを開いてください。ゲームを終了します。
  2. そのフォルダーに MelonLoader 0.7.3 Open-Beta の x64 版をインストールします。必要なら .NET 6 Windows x64 ランタイムも入れてください。MOD を追加する前にゲームを起動する必要はありません。
  3. 公開された BopItAccess-v1.0.zip をダウンロードして展開します。展開したフォルダーを開き、中身をすべて選択して、BopIt!.exe のあるゲームのフォルダーにコピーして貼り付けます。確認されたら、フォルダーの結合とファイルの置き換えを許可してください。ファイルを一つずつコピーする必要はありません。
  4. スクリーンリーダーを使う場合は先に起動し、Steam で Bop It! を起動します。初回は MelonLoader が追加ファイルをダウンロードし、ゲームのアセンブリを準備することがあります。ゲームを開いたまま、MOD の起動案内と、その後のタイトル画面、歓迎画面、またはメインメニューの案内を待ってから操作してください。

手動インストールを更新するときは、ゲームを終了し、新しいコンパイル済み ZIP の中身を再びすべて同じゲームのフォルダーにコピーします。確認されたらフォルダーを結合し、ファイルを置き換えてください。保存済みのゲームと MOD の設定である UserData/BopItAccess.ini は ZIP に含まれません。

手動インストールでは Windows にアンインストーラーは登録されません。BopItAccess-uninstall.ps1 はインストーラーが用意するアンインストーラーへのショートカットであり、このファイルだけでは作成できません。手動で入れた MOD を無効にするには Mods/BopItAccess.dll を削除します。完全に削除したい場合は、インストーラーの「Uninstall」を使ってください。古い手動コピーを検出し、設定の削除を選べるようにし、無関係なファイルを保護します。自分で削除する場合は、この MOD のファイルだけを削除し、ほかの MOD が必要とする共有ファイルは残してください。

MelonLoader の起動ウィンドウ

ZIP の MelonLoader 設定ファイルは、その起動画面とコンソールを非表示にします。インストーラーも同じ初期値を設定します。ゲームのタイトル画面や MOD の歓迎画面は省略されません。

問題の調査のためにこれらのウィンドウを表示したい場合は、ゲームを終了して、ゲームのフォルダーにある UserData/Loader.cfg を開きます。[loader] の disable_start_screen と [console] の hide_console を false に変更してください。MOD は起動のたびにこれらの設定を戻しません。

高度な方法：ソースからビルドする

GitHubのSource codeアーカイブとリポジトリはソースであり、導入可能なDLLではありません。ビルドにはSDKと下記のゲーム参照が必要です。Install alphaはゲームを起動せず参照を準備します。下の手動ソース手順は以前のMelonLoaderゲーム起動を使います。

インストーラーの診断情報

Show advanced を有効にすると Save diagnostics（Alt+D）と Copy diagnostics（Alt+C）が表示されます。自動 UTF-8 ログは %ProgramData%\BopItAccess\diagnostics にローカル保存します。Save diagnostics は選んだ .log または .txt ファイルに現在の完全なセッションを保存し、インストーラーを閉じるまで記録を続けます。Copy diagnostics はその時点の内容をコピーし、アクセシビリティ通知で完了を伝えます。インストールやアンインストールを試す前に保存しておくと、自動ログの削除後も記録を残せます。ステータス欄が短い説明を使っていても、ファイル、ダウンロード、コンパイラー、エラーの技術的詳細は診断情報に残ります。アップロードは行いません。ログには Windows ユーザー名や完全なパスを含む場合があるので、共有前に確認してください。意図的に外部へ保存したコピーはアンインストール後も残ります。

設定ファイルを編集する

知らない言語、大きすぎるゲーム音、または問題のある音声のためにメニューを操作しにくい場合は、ゲームの外から設定を変更できます。起動後、Modは現在の設定を使ってBop It!のゲームフォルダー内にUserData/BopItAccess.iniを自動作成します。メモ帳などのエディターで開けるテキストファイルです。

ファイルには、ゲームの言語、音楽・効果音・ナレーションの音量、振動、全画面表示、解像度、音声遅延、Modの読み上げ・点字・ヒントなどの設定、OneCoreとSAPIの個別の音声設定、プレイヤー向けのゲームとModの操作割り当てが含まれます。利用できる解像度とインストール済みの音声はコメントに記載されます。

編集する前にゲームを終了してください。該当するセクションで既存の項目の値を変更し、ファイルを保存してからゲームを再起動します。変更は起動時に読み込まれ、プレイ中に即座には反映されません。ゲーム内のメニューで変更した設定は、自動的にファイルにも保存されます。

セクション名と設定名は、どの言語でも共通の英語のままです。切り替え項目にはOnとOffをお勧めします。True/False、Yes/No、1/0も使用できます。コメントに選択肢と範囲が説明されています。項目がない場合や値が無効な場合は、その項目の保存済み設定が維持され、他の有効な変更は反映されます。重複した操作割り当ては拒否されます。

コメントと未知の項目は保持されます。ゲームの実行中に他のプログラムがファイルを変更すると、その編集を保護するため、Modはそのセッション中のファイルへの自動保存を停止します。変更を反映するには、ゲームを終了して再起動してください。編集前にバックアップを残しておくこともできます。

各モードの詳しい説明

4 つのモードはすべて、曲/ステージを選択し、クラシックまたはエクストリームを選択することから始まります。ステージでは見るもの、聞くものが変化し、コマンドはどのような入力を行うべきかを指示します。 Classic は、叩く、ねじる、および 引く を要求します。Extreme は、回す および はじく を要求することもできます。ゲームがコマンドを読み上げたら、タイム ウィンドウが終了する前に割り当てられた入力を押します。再生する前に、[設定] > [コントロール] で割り当てを確認または変更できます。実行が成功するとテンポが上がるため、到達するための固定された最後の曲セクションはありません。これらのルールは、 公式ゲーム説明 ゲームの現在のスコアと結果の画面。

ソロ

ソロはリズムを学ぶのに最も簡単な場所です。音声コマンドごとに 1 人が応答します。ゲームに 叩く と表示されている場合は、叩く を入力してください。 ねじる または 引く と表示されている場合は、代わりにその入力を使用してください。 Extreme では、回す と はじく にも備えてください。コマンドが速くなったら続けてください。

採点: 正解するたびに、進行中の実行に 1 ポイントが追加されます。スコアは、成功した応答の数です。応答が間違っていたり、応答が遅れたりすると、その実行は終了します。最終結果画面にはスコアの数値が表示されます。 MOD は、リプレイ、リーダーボード、またはバックを読み取る前にそれをアナウンスします。 「スコアを読む」を押すと、もう一度聞くことができます。ローカル、フレンド、およびグローバル リーダーボード ビューが利用可能な場合、ソロ スコアはこれらのビューにも表示される場合があります。

やり直す方法: 結果画面で [再生] を選択するか、戻って別のモードまたは曲を選択します。リプレイは新しい実行です。以前の結果は、ゲームが記録するリーダーボードで引き続き比較できます。

パーティー

パーティーはグループで順番に参加します。それぞれの人が遊ぶ 自分自身の Solo と同じ種類の呼び出されたコマンドに応答して実行します。人のランが終了すると、ゲームはそのスコアに付ける名前を求めることができます。セッションのパーティー リーダーボードに進み、次の人に順番を渡します。これは、全員が同時に行動することなく実行を比較するためのフレンドリーな方法です。

採点: 成功した応答により、そのプレーヤーの数値的なランスコアが構築されます。間違ったコマンド、失敗したコマンド、または遅れたコマンドによりランが終了し、最終スコアはそのプレーヤーのものとなります。セッション リーダーボードには名前、ランク、スコアがリストされるため、グループは結果を比較できます。ゲームは正式な勝者を 1 人に課すものではありません。あなたのグループは何が勝利としてカウントされるかを決定できます。 MOD はゲームオーバー時にスコアを読み取り、次に選択したメニューを読み上げ、パーティー名とリーダーボードのステップを読み上げます。

プレイを続ける方法: 提示されたら「続行」を使用し、プロンプトが表示されたら名前を選択または確認し、ゲームに従って次のプレーヤーまたはスコア ビューを表示します。リプレイすると、終了したランを延長するのではなく、別の得点されたランが始まります。

バトンタッチ

バトンタッチは、みんなで一つの記録に挑戦するモードです。ゲームがバトンタッチ！と指示するまで、まず一人がコマンドに応えます。その指示が聞こえたら、すみやかに次の人へコントローラーを渡してください。次のプレイヤーは同じ連続記録を引き継ぎます。以後もゲームの指示に従ってコントローラーを渡し、コマンドに応え続けます。誰に渡すかを先に決め、安全に受け渡せる場所で遊びましょう。

採点: 正解すると、各人に新しいスコアが開始されるのではなく、1 つの共有数値スコアが継続されます。コマンドをミスして連続記録を破った人がラウンドを終了します。結果画面には最終的な共有スコアが表示されます。MOD は自動的に読み上げ、スコアの読み取りで繰り返すことができます。スコアはグループがどこまで到達したかを示します。このモードでは、個々のプレイヤーのランキングではありません。

再試行する方法: 新しい共有ストリークを開始するには [再生] を選択し、結果を残すには [戻る] を選択します。

1対1

1 対 1 では 2 人のプレイヤーが参加し、 黄色 そして 緑、同じラウンドに入る。それぞれはから始まります 三つの人生。黄色は ねじる および 引く に応答します。緑は 回す と はじく に応答します。 叩く は共有レースです。両方のプレイヤーが準備を整えている必要があり、最初に 叩く をヒットした人が、ゲームの 3 ライフ制限までライフを獲得します。ゲームでは、いくつかの変更に対して微妙なサウンドが提供されます。 [設定] > [MOD 設定] > [1 対 1 フィードバック] がオン (デフォルト) の場合、MOD はアクティブな色の開始または変更、および損失または利益後のライフの数を通知します。 ライフを獲得した時は、プレイヤーの色と新しい合計を読み上げます。ライフを失った時は、これまでどおり残りの数だけを読み上げます。

ラウンドの終了方法: 必要なコマンドをミスすると、責任のあるプレイヤーは命を落とします。最初にライフがゼロになったプレイヤーが負けとなり、他の色のプレイヤーが勝ちとなります。 Solo、Party、Pass It とは異なり、結果は 勝者、最終スコアの数値ではない。 MOD はゲームオーバー時に勝利の色を発表します。 Read Score は、結果画面が表示されている間、その結果を繰り返します。オプションのライフアナウンスはこのモード専用です。

一緒に準備をしましょう: 始める前に、どちらが黄色でどちらが緑色であるかに同意してください。 1 つの入力デバイスを共有する場合は、現在のコントロール画面、特に 2 番目の 叩く の割り当てを確認してください。 1 対 1 は速いので、練習ラウンドは両方のプレーヤーがコントロールを学ぶのに役立ちます。
