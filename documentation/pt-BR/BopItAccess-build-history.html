Bop It Access: histórico técnico de construção

Um registro cronológico de 59 compilações do mod, de v0.1.0 a v0.9.12, além de versões independentes do instalador. Cada entrada tem um resumo de alterações no escopo e detalhes de implementação. O repositório público GitHub contém código-fonte, sem downloads compilados ou versões GitHub ainda.

Proveniência do Git: O Git foi introduzido após a v0.6.12. Os 37 commits de origem foram reconstruídos a partir de ZIPs de origem preservados; suas datas do Git descrevem a importação, não os eventos de compilação originais. Christopher Shaw é o autor do commit. Os trailers do coautor refletem registros de modelo verificados para o trabalho de construção correspondente: GPT-6 Luna para a primeira construção e GPT-6 Sol para as 36 restantes. Pacotes de instalação local e tags de versão não fazem parte da publicação inicial GitHub.
