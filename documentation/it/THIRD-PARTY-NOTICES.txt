Bop It Access 1.0 utilizza queste librerie runtime di terze parti:

0Harmony.dll - Harmony libreria di patch fornita dal software installato separatamente
MelonLoader. Bop It Access lo usa per osservare quando le impostazioni del gioco finiscono
caricamento alla prima esecuzione della mod. I pacchetti di installazione sorgente e locale no
includere questa DLL; consultare gli avvisi forniti con MelonLoader.

prism.dll — Prism lettore di schermo e libreria di astrazione da testo a voce di
Ethan Dupuy e collaboratori. L'attuale mod Windows x64 utilizza Prism per
output vocale e braille.
Progetto e fonte: https://github.com/ethindp/prism
Licenza: Licenza pubblica Mozilla, versione 2.0.
Testo della licenza: https://github.com/ethindp/prism/blob/master/LICENSE

Questo repository di origine non include alcuna DLL nativa Prism.
Inoltre non include alcuna DLL Bop It Access compilata.
I costruttori devono ottenere o creare separatamente un Windows x64 prism.dll compatibile.
Bop It Access carica Prism dinamicamente in fase di esecuzione.

Le versioni mod precedenti utilizzavano Tolk.dll e nvdaControllerClient64.dll.
i pacchetti di installazione locale preparati contenevano tali DLL e i relativi file applicabili
testi di licenza. Questi pacchetti non sono versioni GitHub e non ne fanno parte
archivio delle fonti. La mod attuale non richiede più quelle DLL.

Strumenti di creazione della traduzione (non necessari o inclusi in fase di esecuzione del gioco):

Argos Translate e i suoi modelli linguistici sono stati utilizzati offline per preparare la bozza
traduzioni del catalogo vocale del mod e dei documenti di progetto. Il monte
il progetto ha doppia licenza MIT o CC0; i suoi pacchetti modello sono offerti sotto
gli stessi termini. Progetto: https://github.com/argosopentech/argos-translate
Licenza MIT: https://github.com/argosopentech/argos-translate/blob/master/LICENSE

Google Translate è stato utilizzato, con l'approvazione del proprietario del progetto, per migliorare il
bozze tradotte automaticamente. Le richieste di traduzione sono avvenute durante la creazione;
la mod non contatta Google né richiede una connessione Internet in fase di esecuzione.

Beautiful Soup 4 è stato utilizzato per preservare la struttura HTML durante la preparazione del file
guide tradotte. Ha la licenza MIT e non fa parte del runtime mod.
Informazioni sul progetto e sulla licenza: https://www.crummy.com/software/BeautifulSoup/

Strumenti alpha e dipendenze runtime dell’installer
---------------------------------------------------

Installer alpha usa Cpp2IL e il plugin StrippedCodeRegSupport di Sam Byass (SamboyCoding) e collaboratori,
sotto licenza MIT. Il2CppInterop dei collaboratori BepInEx è sotto LGPL versione 3; AsmResolver di Washi e
collaboratori sotto MIT. Il2CppInterop e AsmResolver sono forniti da MelonLoader scaricato separatamente. Le
librerie di riferimento Unity restano soggette ai Unity Software Terms e alle relative note; questo progetto
non le concede in licenza. Alpha scarica o riutilizza questi componenti come dati temporanei di compilazione
locale. I loro binari e le assembly proxy del gioco generate non sono inclusi nel repository o nel pacchetto
del mod. Il sorgente dell’helper incorporato chiama librerie esterne e non ne incorpora i binari. Un runtime
mancante per una versione compilata proviene dallo ZIP ufficiale Microsoft .NET 6. Conservare licenza e note
di terze parti incluse; il sorgente .NET è sotto MIT e restano valide le condizioni di distribuzione
Microsoft. Le note restano con i componenti installati.

L’installatore autonomo di Bop It Access per Windows x64 include il runtime .NET 10; non è necessario installare .NET 10 separatamente per eseguirlo. La licenza completa di Microsoft e le note sui componenti di terze parti sono incorporate nell’EXE dell’installatore. Questi componenti mantengono i termini di Microsoft e dei rispettivi autori originali; la licenza MIT di questo progetto non li sostituisce. La mod del gioco continua a utilizzare .NET 6.
