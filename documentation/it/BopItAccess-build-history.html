Il repository pubblico GitHub contiene il codice sorgente, senza ancora download compilati o versioni GitHub.

Provenienza Git: Git è stato introdotto dopo la v0.6.12. I 37 commit di origine sono stati ricostruiti da ZIP di origine conservati; le loro date Git descrivono l'importazione, non gli eventi di build originali. Christopher Shaw è l'autore del commit. I trailer del coautore riflettono i record del modello verificato per il lavoro di build corrispondente: GPT-6 Luna per la prima build e GPT-6 Sol per le restanti 36. I pacchetti di installazione locale e i tag di versione non fanno parte della pubblicazione iniziale GitHub.
