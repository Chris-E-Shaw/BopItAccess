범위와 방법

정적 검토는 Mod와 설치 프로그램의 모든 C# 소스 파일, 제거 스크립트, 프로젝트 빌드 정의, 구성 템플릿, 문서 및 카탈로그 작성 스크립트를 다뤘습니다. 소유권, 종료, 동시성, 탐색 및 재할당 전환, 손상된 파일, 네이티브 대체 경로, 프레임별 작업, 반복 상태 확인, 미사용 코드를 검토했습니다. 병렬 검토자는 음성·오디오·화면, 입력·구성·도구, 설치·복구를 담당했고, 조정 검토자는 라우팅, 힌트, 가이드 탐색, Mod Settings 및 환영 처리를 담당했습니다. 통합된 변경 사항은 두 번째 소스 검토를 받았습니다.

이 문서는 코드 검토 및 컴파일 기록입니다. 이번 변경 사항에 대해 게임 실행, 설치 프로그램 작업, 제거 작업, 자동 테스트 모음 또는 성능 벤치마크를 실행하지 않았습니다. 이전의 사람에 의한 테스트는 여전히 유용하지만 이 리팩터링의 실행 중 동작을 입증하지는 않습니다.

의도적으로 유지한 동작과 코드

  • 자동 최종 점수 음성은 우선순위를 유지하며 요청에 따른 점수 반복은 계속 중단할 수 있습니다. 플레이 중에는 점수를 노출하지 않습니다.
  • 음성과 점자는 계속 Prism을 사용합니다. 자동 모드는 실행 중인 화면 읽기 프로그램, OneCore, SAPI 순서로 선호합니다. 음성 프로필은 별도로 유지합니다.
  • 메뉴 기본값, 저장 환경설정 키, 편집 가능한 INI 이름, 할당, 환영 닫기 규칙, 번역된 플레이어용 문자열의 호환성을 유지합니다.
  • 이전 요청에 따라 숨겨진 Trim Silence 실험을 소스에 유지합니다. 최종 사용자는 계속 사용할 수 없습니다. 실수로 남은 미사용 코드로 취급하지 않았습니다.
  • 과거 빌드 기록, 보존된 소스 가져오기, 이전 작성 도구를 이력 근거로 유지합니다. 오래된 마이그레이션은 기록을 조용히 삭제하지 않고 실행 조건을 제한합니다.
  • 대기열 음성, 네이티브 대체 확인, 잠금 전후의 반복 허용 확인은 순서나 동시 상태 변경을 보호하는 곳에 유지합니다. 구현이 짧아진다는 이유만으로 보호 장치를 제거할 수는 없습니다.
  • 생성된 게임 어셈블리와 컴파일된 Mod·설치 프로그램 파일은 Git 밖에 유지합니다. 빌드 참조는 복사를 비활성화한 채 플레이어 자신의 설치를 계속 사용합니다.
  • 정적 검토에서 결함이 확인되지 않은 네이티브 게임 타이밍, 보정 일정, 점수 규칙, 번역 문구에 추측에 따른 변경을 하지 않았습니다.

컴파일과 실제 한계

통합된 .NET 6 x64 Mod 0.9.8은 Release 및 Debug에서 경고와 오류 0건으로 컴파일되었습니다. Windows x64 독립 실행형 설치 프로그램 0.1.5 게시가 최종 소스 변경 후 진단 0건으로 완료되었습니다. 성공한 컴파일은 실행 중 정확성을 입증하지 않습니다. 이 빌드에 대해 테스트, 게임 실행, 설치, 제거 또는 벤치마크를 수행하지 않았습니다.

Prism P/Invoke 선언을 고정된 v0.18.3 공개 C 헤더와 비교했습니다. 이로써 선언 불일치를 발견할 수 있지만 모든 네이티브 드라이버, 화면 읽기 프로그램, 음성 또는 점자 디스플레이의 동작을 증명할 수는 없습니다.

네이티브 DLL 충돌과 차단된 드라이버 호출은 관리 코드에서 항상 복구할 수는 없습니다. 따라서 종료 대기에 한도를 두고 다른 스레드에서 컨텍스트를 해제하지 않습니다. 실패한 음성 배치는 기록 후 버립니다. 이후 요청은 계속 처리할 수 있지만 실패한 텍스트를 자동으로 다시 읽지는 않습니다.

일부 보정 콜백은 여전히 FMOD 콜백에서 네이티브 상태를 관찰합니다. 기존 보호 처리는 관리 예외를 격리하지만 정적 검토로 모든 스레드 간 타이밍 동작을 증명할 수는 없습니다. 사람의 플레이 테스트 없이 일정을 바꾸면 보정에 영향을 줄 수 있으므로 구체적인 후속 확인 영역으로 남습니다.

가이드는 제공된 HTML 문서용 경량 리더로 유지되며 일반 브라우저는 아닙니다. 새 한도는 비정상적으로 크거나 깊게 중첩된 문서를 의도적으로 거부하고 안전하게 대체 처리합니다. Windows가 프로필 접근을 거부하면 설치 프로그램 정리가 미완료로 남을 수 있습니다. 유지된 실행기와 체크포인트로 나중에 재시도할 수 있습니다.

성능 변경은 확인된 반복 작업과 할당을 제거합니다. 측정된 프레임 속도, 지연 또는 메모리 개선을 주장하지 않습니다. 출시 전 사람의 확인은 네이티브·사용자 지정 재할당, 화면을 여는 입력의 누름·해제, 첫 실행 환영, 모든 가이드 표, 메뉴보다 먼저 읽는 점수 순서, OneCore/SAPI 전환, 백그라운드 동작을 다뤄야 합니다. 설치 프로그램 중단, 중단된 복구, 공유 로더 보존, 환경설정 정리 재시도도 폐기 가능한 테스트 설치에서 확인해야 합니다.

이 검토에서 문제가 발견되지 않았다고 해서 프로젝트에 결함이 없음을 보장하지는 않습니다. 이 빌드는 출시 준비 후보이며 1.0 공개 출시가 아닙니다.

편집 가능한 구성은 지문과 원자적 교체를 사용하지만 마지막 비교와 이름 변경은 운영체제의 compare-and-swap이 아닙니다. 협조하지 않는 편집기가 그 짧은 사이에 쓸 수 있습니다. 강제 종료 시 고유 임시 파일이 남을 수 있으며 제거는 검증된 소유 이름만 삭제합니다. 네이티브 게임·Steam 환경설정 저장은 예외 전에 일부를 기록할 수 있고 공유 트랜잭션 API가 없습니다.

이전 수동 설치에는 영구 소유권 원장이 없습니다. 제거는 알려진 Mod 파일과 안전하게 확인한 종속성만 대상으로 삼을 수 있으며 정리 경고는 열린 설치 프로그램에서 재시도할 수 있습니다. 유지되는 Windows 항목·체크포인트 경로는 설치 프로그램 관리 사본에 적용됩니다. 누락된 백업, 프로필 접근 거부, 사용할 수 없는 드라이브, 보수적인 공유 로더 감지 때문에 나중에 재시도해야 할 수 있습니다. 불확실한 파일을 조용히 삭제하는 대신 이러한 상황을 보고합니다.

입력 자산 정리는 Unity 스레드에서의 응용 프로그램 종료를 위한 것입니다. 향후 게임이 계속 실행되는 즉시 언로드 경로는 참조되는 Mod 입력 자산을 파괴하기 전에 복제된 행과 프롬프트 참조를 제거해야 합니다. 네이티브 드라이버 호출, 여러 컨트롤러 캡처 순서, 보정 콜백은 여전히 사람의 실행 중 확인이 필요합니다.

6개의 Python 작성 스크립트 모두 py_compile 구문 컴파일을 통과했습니다. PowerShell AST 파서는 uninstall.ps1과 prepare_prism.ps1에 대해 구문 오류 0건을 보고했습니다. 이 확인은 스크립트 기능을 실행하거나 종속성을 다운로드하거나 설치·제거를 수행하지 않았습니다.

이식 가능한 SDK는 파일 트랜잭션 전에 준비됩니다. 처리된 취소는 준비 디렉터리를 삭제하지만, 압축 해제 중 전원이 끊기면 이 고유한 디렉터리가 남을 수 있습니다. 일반적인 제거에서는 SDK를 의도적으로 유지합니다. 이전 정리 보조 프로세스가 다시 실행될 때 새 설치 프로그램이 정리 뮤텍스를 소유하고 있다면, 보조 프로세스는 상태 폴더를 유지합니다. 제거 완료 기록을 통해 나중에 정리를 다시 시도할 수 있습니다.
