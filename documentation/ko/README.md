# Bop It Access

Bop It Access은 **Bop It!**의 Windows Steam 버전에 대한 비공식 접근성 모드입니다. MelonLoader를 사용하고 [Prism](https://github.com/ethindp/prism) 메뉴와 게임 화면에 음성 및 점자 피드백을 추가합니다. 현재 기능에는 첫 실행 시작 화면, 게임 내 사용자 가이드, 음성 제목 및 일시 정지 화면, 설정 및 컨트롤, 노래 선택, 최종 점수 및 순위표, 업적, 크레딧, 버튼 힌트, 라운드 전 현재 컨트롤 할당이 포함된 주문형 튜토리얼 텍스트, 4단계에 대한 설명이 포함됩니다. 버전 0.9.0은 음성 및 점자 출력에 Prism를 사용합니다. 모드는 게임에서 선택한 언어를 따르며 게임에서 제공하는 모든 언어에 대한 가이드를 포함합니다.

## 프로젝트 현황

이 프로젝트는 초기 개발 단계에 있습니다. 이 저장소에는 소스 코드와 기술 문서가 포함되어 있습니다. **여기에는 아직 컴파일된 빌드나 GitHub 릴리스가 없습니다.** 이 저장소의 모드를 사용하려면 소스에서 빌드하고 아래 설명된 Prism 런타임을 제공하세요.

커밋 기록에는 37개 이전 빌드의 재구성된 소스 스냅샷이 포함됩니다. 해당 아카이브를 Git으로 가져올 때 커밋이 생성되었습니다. 해당 날짜는 원래 빌드 날짜가 아닙니다. 는 [기술 빌드 기록](BopItAccess-build-history.html) 각 스냅샷의 작업에 대해 설명합니다.

## 요구사항

- Windows x64 및 Steam에 대한 Bop It!의 자체 설치.
- MelonLoader이 게임 디렉토리에 설치되었습니다. 개발에서는 x64 Unity **2022.3.50f1** 게임 빌드와 함께 MelonLoader **0.7.3 Open-Beta**를 사용했습니다. 다른 조합은 확인되지 않았습니다.
- **.NET 6 타겟팅 팩**이 포함된 .NET SDK(mod가 타겟팅하기 때문) `net6.0`.
- 설치의 경우 공식 Windows x64 Prism v0.18.3 `prism.dll`. 이 타사 바이너리는 이 저장소에 없습니다.

모드는 게임 디렉토리 아래 MelonLoader에 의해 생성되거나 설치된 DLL을 참조합니다. 게임 어셈블리를 포함하거나 재배포하지 않습니다.

<a id="build-from-source"></a>
## 소스에서 빌드

1. MelonLoader을 설치하고 Bop It!를 한 번 시작한 다음 게임을 닫습니다. MelonLoader을 생성해야 합니다. `MelonLoader\Il2CppAssemblies` 게임 디렉토리 아래에 있습니다.
2. 이 저장소를 복제하거나 다운로드하세요. 저장소의 루트 디렉터리에서 PowerShell을 엽니다.
3. 세트 `$gameDir` **귀하의** Bop It! 설치 디렉터리로 이동한 후 다음을 빌드하세요.

   ```powershell
   $gameDir = 'C:\Program Files (x86)\Steam\steamapps\common\Bop It!'
   dotnet build .\src\BopItAccess.csproj -c Release "-p:BopItGameDir=$gameDir"
   ```

   예제 경로는 Steam의 일반적인 Windows 위치입니다. Steam 라이브러리가 다른 곳에 있으면 변경하세요. 프로젝트는 필수 MelonLoader 및 생성된 게임 DLL을 확인하고 컴파일하기 전에 누락된 경로를 보고합니다.

4. 빌드된 모드 DLL은 다음 위치에 있습니다. `src\bin\Release\net6.0\BopItAccess.dll`.

SDK에서 .NET 6 타겟팅 팩이 누락되었다고 보고하는 경우 해당 팩이 포함된 SDK를 설치하세요. 프로젝트의 `NuGet.Config` 온라인 패키지 피드를 구성하지 않습니다.

<a id="install-your-build"></a>
## 빌드 설치

1. 게임을 닫습니다. 빌드된 것을 복사하세요. `BopItAccess.dll` 안으로 `<game directory>\Mods\`. 생성 `Mods` MelonLoader이 디렉토리를 생성하지 않은 경우 디렉토리입니다.
2. [Prism 릴리스 페이지](https://github.com/ethindp/prism/releases)에서 Windows x64용 공식 Prism v0.18.3 `prism.dll`을 받거나 같은 버전을 소스에서 빌드합니다. `prism.dll`은 게임 실행 파일이 있는 기본 게임 폴더에 놓으세요. `Mods` 폴더 안에는 넣지 마세요.
3. 빌드 전체 복사 `src\bin\Release\net6.0\documentation\` 폴더를 게임 디렉토리에 넣습니다. 루트에는 영어 가이드가 포함되어 있으며 아래에는 번역된 가이드가 포함되어 있습니다. `fr`, `it`, `de`, `es`, `es-MX`, `ja`, `ko`, `zh`, 그리고 `pt-BR`. 해당 하위 폴더와 동반 문서를 보관하세요. 게임 내 가이드는 열릴 때마다 현재 게임 언어에 대한 HTML을 읽으므로 가이드를 교체하면 DLL을 다시 빌드하지 않고도 콘텐츠가 업데이트됩니다.
4. 스크린 리더를 사용한다면 게임보다 먼저 실행하세요. 호환 스크린 리더가 실행 중이지 않으면 Prism은 OneCore를 우선 사용하고, 사용할 수 없으면 SAPI를 사용합니다.

Bop It Access 빌드 명령은 이 모드만 컴파일합니다. Prism를 빌드하거나 다운로드하지 않습니다. 음성이 시작되지 않으면 검사하십시오. `<game directory>\Mods\BopItAccess.log`. 로그에는 Prism 초기화 및 음성 전달이 기록되어 있지만 성공적인 전달만으로는 오디오가 들렸다는 것을 증명할 수 없습니다.

처음 실행하면 게임의 메인 메뉴가 준비된 후 환영 화면이 나타납니다. 모드 설정을 열거나 게임 내 사용자 가이드를 읽거나 게임을 계속할 수 있습니다. Mod 설정은 또한 **사용자 가이드 열기**와 다음 실행 시 환영 화면을 표시하는 확인된 **환영 화면 재설정** 작업을 제공합니다. 가이드에서 위쪽/아래쪽을 사용하여 주제를 선택하거나 줄을 읽고 확인을 사용하여 항목을 엽니다. 테이블 내에서 왼쪽은 한 열을 왼쪽으로 이동하고, 오른쪽은 한 열을 오른쪽으로 이동하며, 위쪽/아래쪽은 행을 변경하는 동안 현재 열을 유지합니다. 열 머리글은 데이터 행으로 표시되지 않고 셀에 레이블을 지정합니다. 테이블은 입장 시 안내되고 종료 시 종료됩니다. 뒤로는 주제나 가이드를 남깁니다.

게임의 **설정 > 언어** 행에서 언어를 선택하세요. Mod 음성은 해당 선택을 따릅니다. 게임 내 가이드는 일치하는 번역된 HTML 문서를 사용하며, 선택한 사본이 없거나 읽을 수 없는 경우 대체 수단으로 영어를 사용합니다. 번들로 제공되는 영어가 아닌 텍스트는 기계 번역된 첫 번째 단계입니다. 유창하게 말하는 사람의 교정을 환영합니다.

게임 동작 이름에는 게임 자체의 번역을 사용합니다. Shapes, Space, City, Office는 고정된 스테이지 이름이므로 영어로 유지됩니다. OneCore 또는 SAPI의 기본 음성이 게임 언어를 잘 읽지 못하면 모드 설정에서 알맞은 설치된 음성을 선택하세요. 네 가지 음성 설정은 Auto 모드에서도 실제로 사용 중인 OneCore 또는 SAPI의 이름을 표시합니다. 지원되는 설정만 나타나며 다른 출력 방식에서는 숨겨집니다. 두 엔진의 음성, 볼륨, 속도, 음높이는 따로 저장됩니다.

## AI 투명성

Christopher Shaw는 이 프로젝트를 감독하고 게임 내 접근성을 평가합니다. OpenAI Codex 모델은 연구, 코드 및 문서화를 지원했습니다. 게시된 커밋 메시지에는 다음이 포함됩니다. `Co-authored-by` 각 변경에 기여한 모델을 식별하는 예고편 이 프로젝트의 세션 기록과 비교하여 과거 크레딧을 확인했습니다. 이전 빌드 기록은 당시 커밋으로 기록되지 않고 저장된 소스 아카이브에서 재구성되었습니다. AI 지원 기여에는 실수가 포함될 수 있으므로 사용하기 전에 검토해야 합니다.
