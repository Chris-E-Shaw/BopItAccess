# Bop It Access

Bop It Access은 **Bop It!**의 Windows Steam 버전에 대한 비공식 접근성 모드입니다. MelonLoader를 사용하고 [Prism](https://github.com/ethindp/prism) 메뉴와 게임 화면에 음성 및 점자 피드백을 추가합니다. 현재 기능에는 첫 실행 시작 화면, 게임 내 사용자 가이드, 음성 제목 및 일시 정지 화면, 설정 및 컨트롤, 노래 선택, 최종 점수 및 순위표, 업적, 크레딧, 버튼 힌트, 라운드 전 현재 컨트롤 할당이 포함된 주문형 튜토리얼 텍스트, 4단계에 대한 설명이 포함됩니다. 버전 0.9.0은 음성 및 점자 출력에 Prism를 사용합니다. 모드는 게임에서 선택한 언어를 따르며 게임에서 제공하는 모든 언어에 대한 가이드를 포함합니다.

## 설정 파일 편집

모르는 언어, 너무 큰 게임 소리 또는 문제가 있는 음성 때문에 메뉴를 사용하기 어렵다면 게임 밖에서 설정을 바꿀 수 있습니다. 시작 후 모드는 현재 설정을 사용해 Bop It! 게임 폴더 안에 UserData/BopItAccess.ini를 자동으로 만듭니다. 메모장 같은 편집기로 열 수 있는 일반 텍스트 파일입니다.

파일에는 게임의 언어, 음악·효과음·음성 안내 볼륨, 진동, 전체 화면, 해상도와 오디오 지연, 모드의 음성·점자·힌트 등의 설정, 별도로 저장되는 OneCore와 SAPI 음성 설정, 플레이어가 사용하는 게임 및 모드 입력 할당이 포함됩니다. 사용할 수 있는 해상도와 설치된 음성은 주석에 표시됩니다.

편집하기 전에 게임을 종료하세요. 해당 구역에서 기존 항목의 값을 바꾸고 파일을 저장한 다음 게임을 다시 시작하세요. 변경 사항은 실행할 때 읽으며, 게임이 실행 중일 때 바로 적용되지는 않습니다. 게임 메뉴에서 바꾼 설정은 파일에도 자동으로 저장됩니다.

구역 이름과 설정 이름은 모든 언어에서 영어로 유지됩니다. 켜기와 끄기는 On과 Off를 권장하며 True/False, Yes/No, 1/0도 사용할 수 있습니다. 주석에 선택 항목과 범위가 설명되어 있습니다. 누락되거나 잘못된 값은 해당 저장 설정을 그대로 유지하며, 다른 올바른 변경 사항은 적용됩니다. 중복된 입력 할당은 거부됩니다.

주석과 알 수 없는 항목은 유지됩니다. 게임 실행 중 다른 프로그램이 파일을 수정하면 그 편집을 보호하기 위해 모드가 해당 세션의 남은 시간 동안 파일 자동 저장을 중단합니다. 적용하려면 게임을 종료하고 다시 실행하세요. 편집 전에 백업을 남길 수도 있습니다.

음성에 문제가 있으면 OneCore 또는 SAPI 구역에서 Voice=System default로 설정하세요. OneCore 음성은 이름 | 언어 형식을 사용합니다. SAPI는 설치된 음성의 표시 이름이나 전체 레지스트리 ID를 사용할 수 있습니다. 파일에 사용 가능한 선택 항목이 나옵니다. OutputMode=Auto는 실행 중인 지원 스크린 리더, OneCore, SAPI 순으로 시도합니다.

아래 예시는 언어를 영어로 바꾸고 게임 소리를 낮추며 시스템 기본 음성을 사용하는 자동 음성 출력을 복원합니다. 파일에 이미 있는 해당 항목을 수정하세요. 이 내용은 참고용 발췌이며 파일 끝에 추가할 새 구역이 아닙니다. 다른 설정은 그대로 두세요.

```ini
[Game]
Language=en
MusicVolume=30
SfxVolume=30
VoiceOverVolume=30

[Mod]
SpeechOutput=On
OutputMode=Auto

[OneCore]
Voice=System default

[SAPI]
Voice=System default
```

Uninstall을 확인한 뒤 Uninstall for me 또는 Uninstall for everyone을 선택하세요. 둘 다 이 게임 폴더의 공유 모드 파일을 제거하므로 해당 설치를 사용하는 누구도 모드를 사용할 수 없게 됩니다. 선택에 따라 달라지는 것은 Windows에 저장된 모드 기본 설정의 제거 대상입니다. 요청한 사용자 계정만 제거할지, 로그아웃한 프로필을 포함한 모든 로컬 Windows 프로필에서 제거할지 선택합니다. 원래 게임의 기본 설정은 유지합니다. .NET SDK도 설치된 상태로 남습니다.

설치 프로그램이 직접 설치한 MelonLoader를 제거하고 다른 모드가 필요로 하지 않으면 알려진 Loader.cfg와 MelonPreferences.cfg 파일 및 비어 있는 Plugins, UserLibs, UserData 폴더도 제거합니다. Bop It Access 설정, 알려진 로그, 가이드 및 설치 프로그램 파일을 제거합니다. 다른 모드, 기존 공유 로더 파일 및 인식하지 못한 파일은 보호합니다. 따라서 알 수 없는 파일이 있으면 폴더가 남을 수 있습니다. 무관한 데이터를 삭제하는 대신 진단 정보에 이를 기록합니다.

Windows 설치된 앱에서도 같은 확인, 기본 설정 범위 선택 및 정리를 사용합니다. 설치 프로그램은 게임 폴더에 BopItAccess-uninstall.ps1을 제공하며 이 파일은 설치된 제거 프로그램으로 연결하는 바로 가기입니다. 앞으로의 소스 빌드 출력에도 이 스크립트가 포함됩니다. 스크립트를 수동으로 복사하는 것만으로 제거 프로그램 자체가 설치되지는 않습니다. 소유권 기록이 없는 이전 수동 설치는 식별 가능한 모드 파일을 제거하고 출처를 확인할 수 없는 공유 파일은 유지합니다.

안전하게 정리를 마칠 수 없으면 이유를 설명하고 재시도에 필요한 정보를 유지합니다. 관리되는 설치에서는 제거가 성공할 때까지 Windows 제거 항목과 정리 체크포인트가 남습니다. 이전 수동 설치에는 지속적인 소유권 기록이 없으므로 열려 있는 설치 프로그램에서 경고된 작업을 재시도하세요. Bop It!이 실행 중일 때는 모드를 설치, 업데이트 또는 제거하지 마세요.

## 프로젝트 현황

이 프로젝트는 기본적으로 완료되었으며 주요 콘텐츠나 기능은 계획되어 있지 않습니다. 플레이어 피드백을 통해 개선 사항을 안내하면서 필요에 따라 유지 관리됩니다. GitHub 저장소에는 소스 코드와 기술 문서가 포함되어 있습니다. **아직 GitHub 릴리스가 없습니다.** 이제 소스에는 Windows 설치 프로그램 프로젝트도 포함되어 있습니다. 릴리스가 게시될 때까지 **설치** 버튼은 사용 가능한 릴리스가 없다고 설명합니다. **알파 설치**는 소스에서 최신 기본 브랜치 커밋을 빌드합니다.

커밋 기록에는 37개 이전 빌드의 재구성된 소스 스냅샷이 포함됩니다. 해당 아카이브를 Git으로 가져올 때 커밋이 생성되었습니다. 해당 날짜는 원래 빌드 날짜가 아닙니다. 는 [기술 빌드 기록](BopItAccess-build-history.html) 각 스냅샷의 작업에 대해 설명합니다.

## 요구사항

- Windows x64 및 Steam에 대한 Bop It!의 자체 설치.
- MelonLoader이 게임 디렉토리에 설치되었습니다. 개발에서는 x64 Unity **2022.3.50f1** 게임 빌드와 함께 MelonLoader **0.7.3 Open-Beta**를 사용했습니다. 다른 조합은 확인되지 않았습니다.
- **.NET 6 타겟팅 팩**이 포함된 .NET SDK(mod가 타겟팅하기 때문) `net6.0`.
- 설치의 경우 공식 Windows x64 Prism v0.18.3 `prism.dll`. 이 타사 바이너리는 이 저장소에 없습니다.

모드는 게임 디렉토리 아래 MelonLoader에 의해 생성되거나 설치된 DLL을 참조합니다. 게임 어셈블리를 포함하거나 재배포하지 않습니다.

## 소스에서 빌드

1. MelonLoader을 설치하고 Bop It!를 한 번 시작한 다음 게임을 닫습니다. MelonLoader을 생성해야 합니다. `MelonLoader\Il2CppAssemblies` 게임 디렉토리 아래에 있습니다.
2. 이 저장소를 복제하거나 다운로드하세요. 저장소의 루트 디렉터리에서 PowerShell을 엽니다.
3. 세트 `$gameDir` **귀하의** Bop It! 설치 디렉터리로 이동한 후 다음을 빌드하세요.

   ```powershell
   $gameDir = 'C:\Program Files (x86)\Steam\steamapps\common\Bop It!'
   dotnet build .\src\BopItAccess.csproj -c Release "-p:BopItGameDir=$gameDir"
   ```

   예제 경로는 Steam의 일반적인 Windows 위치입니다. Steam 라이브러리가 다른 곳에 있으면 변경하세요. 프로젝트는 필수 MelonLoader 및 생성된 게임 DLL을 확인하고 컴파일하기 전에 누락된 경로를 보고합니다.

4. 빌드된 모드 DLL은 다음 위치에 있습니다. `src\bin\Release\net6.0\BopItAccess.dll`.

SDK에서 .NET 6 타겟팅 팩이 누락되었다고 보고하는 경우 해당 팩이 포함된 SDK를 설치하세요. 프로젝트의 `NuGet.Config` 온라인 패키지 피드를 구성하지 않습니다.

<a id="install-your-build"></a>
## 빌드 설치

1. 게임을 닫습니다. 빌드된 것을 복사하세요. `BopItAccess.dll` 안으로 `<game directory>\Mods\`. 생성 `Mods` MelonLoader이 디렉토리를 생성하지 않은 경우 디렉토리입니다.
2. [Prism 릴리스 페이지](https://github.com/ethindp/prism/releases)에서 Windows x64용 공식 Prism v0.18.3 `prism.dll`을 받거나 같은 버전을 소스에서 빌드합니다. `prism.dll`은 게임 실행 파일이 있는 기본 게임 폴더에 놓으세요. `Mods` 폴더 안에는 넣지 마세요.
3. 빌드 전체 복사 `src\bin\Release\net6.0\documentation\` 폴더를 게임 디렉토리에 넣습니다. 루트에는 영어 가이드가 포함되어 있으며 아래에는 번역된 가이드가 포함되어 있습니다. `fr`, `it`, `de`, `es`, `es-MX`, `ja`, `ko`, `zh`, 그리고 `pt-BR`. 해당 하위 폴더와 동반 문서를 보관하세요. 게임 내 가이드는 열릴 때마다 현재 게임 언어에 대한 HTML을 읽으므로 가이드를 교체하면 DLL을 다시 빌드하지 않고도 콘텐츠가 업데이트됩니다.
4. 스크린 리더를 사용한다면 게임보다 먼저 실행하세요. 호환 스크린 리더가 실행 중이지 않으면 Prism은 OneCore를 우선 사용하고, 사용할 수 없으면 SAPI를 사용합니다.

Bop It Access 빌드 명령은 이 모드만 컴파일합니다. Prism를 빌드하거나 다운로드하지 않습니다. 음성이 시작되지 않으면 검사하십시오. `<game directory>\Mods\BopItAccess.log`. 로그에는 Prism 초기화 및 음성 전달이 기록되어 있지만 성공적인 전달만으로는 오디오가 들렸다는 것을 증명할 수 없습니다.

처음 실행하면 게임의 메인 메뉴가 준비된 후 환영 화면이 나타납니다. 모드 설정을 열거나 게임 내 사용자 가이드를 읽거나 게임을 계속할 수 있습니다. Mod 설정은 또한 **사용자 가이드 열기**와 다음 실행 시 환영 화면을 표시하는 확인된 **환영 화면 재설정** 작업을 제공합니다. 가이드에서 위쪽/아래쪽을 사용하여 주제를 선택하거나 줄을 읽고 확인을 사용하여 항목을 엽니다. 테이블 내에서 왼쪽은 한 열을 왼쪽으로 이동하고, 오른쪽은 한 열을 오른쪽으로 이동하며, 위쪽/아래쪽은 행을 변경하는 동안 현재 열을 유지합니다. 열 머리글은 데이터 행으로 표시되지 않고 셀에 레이블을 지정합니다. 테이블은 입장 시 안내되고 종료 시 종료됩니다. 뒤로는 주제나 가이드를 남깁니다.

게임의 **설정 > 언어** 행에서 언어를 선택하세요. Mod 음성은 해당 선택을 따릅니다. 게임 내 가이드는 일치하는 번역된 HTML 문서를 사용하며, 선택한 사본이 없거나 읽을 수 없는 경우 대체 수단으로 영어를 사용합니다. 번들로 제공되는 영어가 아닌 텍스트는 기계 번역된 첫 번째 단계입니다. 유창하게 말하는 사람의 교정을 환영합니다.

게임 동작 이름에는 게임 자체의 번역을 사용합니다. Shapes, Space, City, Office는 고정된 스테이지 이름이므로 영어로 유지됩니다. OneCore 또는 SAPI의 기본 음성이 게임 언어를 잘 읽지 못하면 모드 설정에서 알맞은 설치된 음성을 선택하세요. 음성, 볼륨, 말하기 속도, 음높이는 Auto 모드에서도 실제로 사용 중인 OneCore 또는 SAPI를 조절합니다. 지원되는 설정만 나타나며 다른 출력 방식에서는 숨겨집니다. 두 엔진의 설정은 따로 저장됩니다.

메뉴 항목 위치 읽기. 이 설정은 저장되며 기본적으로 켜져 있습니다. 선택한 항목이 메뉴에서 몇 번째인지 읽습니다. 일대일 피드백 설정은 저장되며 기본적으로 켜져 있습니다. 시작할 때와 바뀔 때 현재 색상을 읽습니다. 생명을 잃으면 남은 개수만 읽습니다. 생명을 얻으면 “초록, 생명 3개”처럼 플레이어의 색상과 새 총개수를 읽어 누가 먼저 치기 입력을 했는지 알 수 있습니다. 일대일 피드백을 끄면 이 안내가 나오지 않습니다.게임의 생명 한도는 기존처럼 3개입니다. 이 기능은 일대일 플레이 중에만 작동합니다. 마지막 보정 입력이 등록되면 모드는 즉시 “완료!”라고 읽습니다. 치기를 멈추고 측정 결과를 기다리세요. 입력을 하지 않아 보정이 실패하면 “보정에 실패했습니다.”라고 읽습니다.

**음성 문구 다듬기**: 모두 대문자인 영문을 음성과 점자에서 자연스럽게 읽도록 다듬습니다. 게임 내 가이드에서 줄 끝에 문장 부호가 없으면 줄 번호 앞에 말줄임표를 넣어 잠시 쉬게 합니다. 화면의 글자는 바뀌지 않습니다. 끄면 원래 문구를 그대로 출력합니다.

### MelonLoader 시작 창

제공된 Loader.cfg 템플릿은 MelonLoader의 별도 시작 화면과 콘솔을 숨깁니다. 설치 프로그램은 사용자가 직접 게임을 실행하기 전에 두 기본값을 적용합니다. 게임 타이틀 화면이나 모드 환영 화면을 건너뛰지는 않습니다.

게임을 종료한 상태에서 게임 폴더의 `UserData/Loader.cfg`를 엽니다. 파일이 이미 있다면 기존 `[loader]` 섹션의 `disable_start_screen` 값을 `true`로, 기존 `[console]` 섹션의 `hide_console` 값을 `true`로 설정합니다. 다른 항목은 변경하지 마세요. 파일이 없다면 빌드에 포함된 `UserData/Loader.cfg` 템플릿이나 소스 코드의 `configuration/Loader.cfg`를 복사합니다. 기존 Loader.cfg 파일을 템플릿 전체로 덮어쓰지 마세요.

```ini
[loader]
disable_start_screen = true

[console]
hide_console = true
```

모드는 시작할 때마다 이 옵션을 초기화하지 않습니다. 문제 해결을 위해 필요하면 두 값을 수동으로 false로 바꿀 수 있습니다. 제거 후 공유 MelonLoader를 유지할 경우 설치 프로그램의 변경값이 그대로인 대상 항목만 원래대로 복원하고 다른 편집 내용은 유지합니다. 설치 프로그램이 직접 설치한 불필요한 MelonLoader를 제거하는 경우 알려진 Loader.cfg 및 MelonPreferences.cfg도 제거합니다.

## Windows 설치 프로그램 미리 보기 0.2.2

Bop It!을 종료한 뒤 설치 프로그램을 열고 Windows 관리자 확인을 승인하세요. 설치 프로그램은 환영 메시지를 표시하고 사용 가능한 모든 드라이브의 Steam 라이브러리에서 게임을 찾은 다음 창을 앞으로 가져오려고 합니다. 표시된 게임 폴더를 확인하고 다른 폴더를 선택하려면 Browse를 사용하세요. Tab으로 항목 사이를 이동합니다. 상태 로그는 읽기 전용 텍스트 필드입니다. 포커스를 옮겨 커서 키로 메시지를 살펴보고 텍스트를 선택하거나 복사할 수 있습니다.

설치 프로그램 0.2.2는 시작 시 잠시 전경 활성화와 키보드 포커스를 요청합니다. 제한된 시작 관찰이 끝나도 다른 창이 활성 상태이면 제목과 작업 표시줄 버튼을 깜박이고 Alt+Tab으로 설치 프로그램으로 전환하라고 안내합니다. 키보드나 컨트롤러 조작 전에 설치 프로그램을 활성화하세요. Alt+G는 게임 폴더 필드에 포커스를 맞춥니다.

설치 프로그램을 열면 Show advanced는 선택되어 있지 않습니다. 선택하면 Install alpha, Save diagnostics, Copy diagnostics가 나타납니다. Install은 공개된 GitHub 릴리스가 있을 때 최신 버전을 다운로드합니다. 아직 공개 릴리스가 없으므로 테스터는 Show advanced를 선택하고 Install alpha를 사용해야 합니다. Alpha는 확인을 받은 후 최신 소스를 다운로드해 사용자의 컴퓨터에서 빌드합니다. 설치된 버전보다 새로운 공개 릴리스가 발견되면 Update가 나타납니다.

상태 메시지는 무엇을 다운로드하거나 설치하고 완료하는지 쉬운 말로 설명합니다. 하나의 진행률 표시줄이 전체 설치의 예상 진행률을 나타내며 다운로드나 파일마다 처음부터 다시 시작하지 않습니다. 5퍼센트포인트 단위로 증가합니다. 일부 준비 단계에서는 표시가 바뀌지 않아도 시간이 걸릴 수 있습니다. 환영 메시지, 새로운 업데이트 안내, 진단 정보 복사 완료는 Windows 접근성 알림을 통해 화면 읽기 프로그램에 전달합니다. 실제로 읽는지는 화면 읽기 프로그램과 Windows 알림 지원에 따라 달라집니다.

설치 프로그램 0.2.2은 설치 중 Bop It!을 실행하지 않습니다. Alpha는 일치하는 로컬 빌드 파일을 재사용하거나 게임을 종료한 상태에서 설치된 게임의 파일로 임시 파일을 준비합니다. 그런 다음 게임 폴더에 MelonLoader를 배치하고 즉시 Mods/BopItAccess.dll을 추가합니다. 이어서 Prism, 설정, 전체 문서 및 제거 지원 파일을 설치합니다. 성공 메시지를 기다린 후 준비가 되면 직접 Steam에서 게임을 실행하세요.

설치가 성공하면 Play Bop It! The Video Game이 나타납니다. 준비되면 선택하여 직접 Steam을 통해 게임을 실행하세요. 설치 프로그램은 설치 중 자동으로 게임을 시작하지 않습니다.

컴파일된 릴리스에는 Windows x64 .NET 6 런타임이 필요하며 개발용 SDK는 필요하지 않습니다. 완전한 기존 런타임은 재사용합니다. 런타임이 없으면 Microsoft에서 다운로드하여 MelonLoader/Dependencies/dotnet에 배치합니다. Install alpha에는 호환되는 .NET SDK와 .NET 6 대상 지정 팩도 필요합니다. 기존 SDK를 재사용하거나 Microsoft 공식 SDK를 시스템 전체에 설치합니다. 게임 루트에는 새 SDK 폴더를 만들지 않습니다. MelonLoader 0.7.3 Open-Beta와 Prism 0.18.3은 공식 릴리스에서 가져옵니다. 공유 Microsoft .NET 구성 요소와 SDK는 중단 또는 제거 후에도 설치된 상태로 남습니다.

Quit은 설치 프로그램을 종료합니다. 설치가 진행 중이면 닫기 전에 중단하고 변경 사항을 되돌릴지 묻습니다. Keep open을 선택하면 계속 진행합니다. 사용자가 결정하는 사이 설치가 끝나면 대화 상자는 완료된 상태로 안내를 갱신하며 Quit으로 완료된 설치를 취소하지 않습니다. 제거가 시작된 경우 안전하게 끝난 후 종료합니다. Abort도 확인을 요청하고 이번 시도의 게임 파일 변경 사항을 되돌립니다. Microsoft .NET 설치 중 취소하면 공유 구성 요소 설치가 안전하게 끝날 때까지 기다립니다.

Uninstall을 확인한 뒤 Uninstall for me 또는 Uninstall for everyone을 선택하세요. 둘 다 이 게임 폴더의 공유 모드 파일을 제거하므로 해당 설치를 사용하는 누구도 모드를 사용할 수 없게 됩니다. 선택에 따라 달라지는 것은 Windows에 저장된 모드 기본 설정의 제거 대상입니다. 요청한 사용자 계정만 제거할지, 로그아웃한 프로필을 포함한 모든 로컬 Windows 프로필에서 제거할지 선택합니다. 원래 게임의 기본 설정은 유지합니다. .NET SDK도 설치된 상태로 남습니다.

설치 프로그램이 직접 설치한 MelonLoader를 제거하고 다른 모드가 필요로 하지 않으면 알려진 Loader.cfg와 MelonPreferences.cfg 파일 및 비어 있는 Plugins, UserLibs, UserData 폴더도 제거합니다. Bop It Access 설정, 알려진 로그, 가이드 및 설치 프로그램 파일을 제거합니다. 다른 모드, 기존 공유 로더 파일 및 인식하지 못한 파일은 보호합니다. 따라서 알 수 없는 파일이 있으면 폴더가 남을 수 있습니다. 무관한 데이터를 삭제하는 대신 진단 정보에 이를 기록합니다.

제거 후에도 설치 프로그램은 열려 있어 결과를 검토하고 진단 정보를 저장하거나 다시 설치할 수 있습니다. 마쳤으면 Quit을 선택하세요. 실행 중인 제거 보조 파일과 자동 진단 로그는 창을 닫은 후 정리합니다. 같은 창에서 다시 설치하면 새로운 설치 기록을 시작하며 이전 제거의 지연 정리가 새 설치를 삭제하지 않습니다.

Windows 설치된 앱에서도 같은 확인, 기본 설정 범위 선택 및 정리를 사용합니다. 설치 프로그램은 게임 폴더에 BopItAccess-uninstall.ps1을 제공하며 이 파일은 설치된 제거 프로그램으로 연결하는 바로 가기입니다. 앞으로의 소스 빌드 출력에도 이 스크립트가 포함됩니다. 스크립트를 수동으로 복사하는 것만으로 제거 프로그램 자체가 설치되지는 않습니다. 소유권 기록이 없는 이전 수동 설치는 식별 가능한 모드 파일을 제거하고 출처를 확인할 수 없는 공유 파일은 유지합니다.

안전하게 정리를 마칠 수 없으면 이유를 설명하고 재시도에 필요한 정보를 유지합니다. 관리되는 설치에서는 제거가 성공할 때까지 Windows 제거 항목과 정리 체크포인트가 남습니다. 이전 수동 설치에는 지속적인 소유권 기록이 없으므로 열려 있는 설치 프로그램에서 경고된 작업을 재시도하세요. Bop It!이 실행 중일 때는 모드를 설치, 업데이트 또는 제거하지 마세요.

| Copy diagnostics | Alt+C | 전체 진단 스냅샷을 복사합니다. Show advanced로 표시됩니다. |
| Quit | Alt+Q | 작업 중이면 안전한 취소 처리를 거쳐 닫습니다. |

### 설치 프로그램에서 컨트롤러 사용

설치 프로그램은 Xbox형 컨트롤러와 Windows가 XInput으로 노출하는 다른 컨트롤러를 지원합니다. 이 조작은 게임의 재할당 가능한 조작과 별개입니다. 방향 패드 또는 왼쪽 스틱으로 항목 사이를 이동합니다. 텍스트 필드에 포커스가 있으면 방향 입력은 대신 텍스트를 검토합니다. 범퍼는 항상 이전 또는 다음 포커스 가능한 항목으로 이동합니다. A는 선택한 버튼이나 체크박스를 작동합니다. 이 설치 프로그램이나 자체 대화 상자가 전경에 있을 때만 컨트롤러 입력을 처리합니다.

B는 대화 상자에서 뒤로 가거나 취소합니다. 메인 설치 창에서는 설치 중일 때 중단을 요청하고 그렇지 않으면 Quit과 같은 동작을 합니다. Start는 메인 창에서 Quit, 대화 상자에서는 뒤로 가기입니다. Y(전면 위쪽 버튼)는 설치 프로그램의 텍스트 필드에 포커스가 있으면 전체 텍스트를 선택합니다. 메인 창의 텍스트 필드 밖에서는 Show advanced를 전환합니다. 상태 로그나 설치 프로그램의 다른 텍스트 필드에서는 방향 패드 또는 왼쪽 스틱이 화살표 키처럼 작동합니다. 왼쪽/오른쪽은 문자 단위, 위/아래는 줄 단위로 이동합니다. LT를 누르면 Ctrl처럼 작동하여 왼쪽/오른쪽은 단어 단위, 위/아래는 문단 단위로 이동합니다. RT를 누르면 Shift처럼 선택 영역을 확장하며, LT와 RT를 함께 누르면 단어나 문단을 선택합니다. X는 선택한 텍스트만 복사하므로 먼저 원하는 부분을 선택하세요. 키보드 Ctrl+C도 계속 선택 영역을 복사합니다. 선택한 텍스트가 없으면 설치 프로그램은 커서 위치의 문자, 단어, 줄 또는 문단에 대한 접근성 알림도 보냅니다. 설치 프로그램은 텍스트가 복사되면 접근성 확인 알림을 보내며, 선택 영역이 없거나 복사가 실패하면 이를 알립니다. 음성으로 읽히는지는 스크린 리더의 Windows 알림 지원에 따라 달라집니다. Windows 기본 폴더 및 저장 대화 상자의 컨트롤러 탐색은 아직 사람의 확인이 필요합니다. 폴더나 파일 이름 입력에는 키보드를 사용할 수 있습니다. XInput을 지원하지 않는 컨트롤러는 이번 구현에 포함되지 않습니다.

상태 로그의 환영 메시지에는 컨트롤러 텍스트 검토 단축키가 나열됩니다. Alt+L로 로그로 돌아갈 수 있습니다. Show advanced를 변경하면 선택 또는 선택 해제 상태를 알리는 Windows 접근성 알림을 보냅니다. 전체 선택도 접근성 확인 알림을 제공하며, 필드가 비어 있으면 이를 알립니다.

### 설치 프로그램 진단 정보

Show advanced를 선택하면 Save diagnostics(Alt+D)와 Copy diagnostics(Alt+C)가 나타납니다. 자동 UTF-8 로그는 %ProgramData%\BopItAccess\diagnostics에 로컬로 저장합니다. Save diagnostics는 선택한 .log 또는 .txt 파일에 현재 전체 세션을 저장하고 설치 프로그램을 닫을 때까지 기록을 계속합니다. Copy diagnostics는 현재 내용을 복사하고 접근성 알림으로 완료를 알립니다. 설치나 제거를 시도하기 전에 저장하여 자동 로그 정리 후에도 기록을 유지하세요. 상태 필드는 짧은 메시지를 사용하지만 파일, 다운로드, 컴파일러 및 오류의 기술적 세부 정보는 진단에 남습니다. 업로드하지 않습니다. 로그에는 Windows 사용자 이름과 전체 경로가 포함될 수 있으므로 공유 전에 검토하세요. 의도적으로 외부에 저장한 복사본은 제거 후에도 남습니다.

MelonLoader 설치 후 처음 직접 게임을 실행하면 지원 파일을 다운로드하고 게임 어셈블리를 준비할 수 있습니다. 약 1분, 일부 시스템에서는 그 이상 기다려 주세요. MelonLoader가 모드를 로드하기 전에는 모드가 말할 수 없습니다. 게임을 열어 둔 채 Bop It Access 시작 안내를 기다리고 제목 화면, 환영 화면 또는 메인 메뉴 안내가 나온 후 게임 조작을 사용하세요.
