feat(installer): 컨트롤러 전체 선택 및 명확한 컨트롤 상태 알림 추가

  • 사용자는 설치 프로그램 0.2.1의 컨트롤러 텍스트 이동, 선택 및 복사가 작동한다고 확인했습니다. 파일 탐색기에서 열 때 초기 전경 활성화와 키보드 포커스는 여전히 실패합니다. 이 사람의 결과는 사람의 확인을 기다리는 0.2.2의 새 동작과 별도로 기록합니다.
  • 관리 코드 시작 직후 설치 프로그램 자신의 PID에 AllowSetForegroundWindow를 요청하고 허용 또는 거부를 기록합니다. 프로세스가 이미 가진 권한을 유지할 수 있지만 없는 권한을 만들거나 Windows 전경 정책을 변경할 수는 없습니다. 125ms 타이머로 시작을 최대 2초 동안 관찰합니다. 서로 다른 전경 창마다 한 번씩 최대 3회 활성화를 요청하며, 실제 전경/컨트롤 포커스가 확인되어 250ms 동안 안정되면 멈춥니다. 새 사용자 입력, 활성화된 컨트롤의 의도적 포커스 변경, 작업 또는 자체 대화 상자 전환에도 멈춥니다. 효과가 없던 임시 최상위 표시를 제거합니다. 시간 또는 전경 전환 횟수 제한 후 다른 창이 활성 상태이면 설치 프로그램 제목/작업 표시줄을 3회 깜박이고 화면 상태와 중요한 기본 스크린 리더 안내로 Alt+Tab 전환을 알립니다. Windows는 여전히 활성화를 거부할 수 있으며, 전경 프로세스 정보는 정확한 원인을 식별하지 않습니다. 관리 코드에서 처음 관찰한 전경 실행 파일 이름/핸들, 관리자 토큰 상태 및 네이티브 프로세스 경과 시간을 기록하며 창 제목이나 인수는 포함하지 않습니다.
  • 전면 위쪽 버튼 Y는 포커스가 있는 설치 프로그램 텍스트 필드의 전체 텍스트를 선택하며 자체 기본 편집 컨트롤도 포함합니다. 선택 앵커를 시작에, 활성 커서를 끝에 유지하여 이후 RT 방향 입력으로 선택을 조정할 수 있게 합니다. 전체 선택 성공 또는 빈 필드에는 중요한 Windows 접근성 알림을 제공합니다. 메인 창의 텍스트 필드 밖에서는 Y가 계속 Show advanced를 전환합니다. X는 선택 영역만 복사합니다.
  • 화면과 접근성 환영 메시지에 컨트롤러 포커스, 문자/줄 검토, LT 단어/문단 이동, RT 선택, 두 트리거 동시 사용, Y 전체 선택 및 X 복사를 추가합니다. Show advanced에 명시적 체크박스 역할을 부여하고 입력 방법과 관계없이 상태가 변경될 때마다 선택 또는 선택 해제 상태를 보이는 상태 메시지 및 중요한 기본 UI Automation 알림으로 제공합니다.
  • 영문 README와 안내서, 9개 언어 번역본 및 설치 프로그램 기술 문서를 업데이트합니다. 모든 이전 기록 문서와 기존 앵커를 보존합니다. Windows x64용 자체 포함 설치 프로그램 0.2.2를 경고 0개, 오류 0개로 게시했으며 git diff --check에서도 문제가 없습니다. 정적 PE 검사는 포함된 세 리소스가 소스 바이트와 정확히 일치함을 확인합니다. 단일 파일 번들에는 일치하는 기본 DLL이 포함되어 있으며 설치 프로그램 전용 언어 위성 리소스는 없습니다. 검증은 컴파일과 정적 검사로 제한됩니다. 자동 테스트, 설치 프로그램/제거 프로그램, 컨트롤러 또는 스크린 리더 실행, 참조 생성, 게임 실행은 수행하지 않았습니다. 포커스 문제가 해결되었다는 사실은 입증되지 않았습니다. 새로운 전체 선택 및 상태/주의 알림은 사람의 확인을 기다립니다.
  • 기본 모드는 v0.9.11, 모드 빌드는 58개로 유지됩니다. 새 모드 DLL, 태그 또는 GitHub Release를 만들지 않습니다.
