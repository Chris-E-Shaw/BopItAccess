Bop It Access: 기술 빌드 기록

v0.8.1를 통해 v0.1.0에서 46 빌드의 연대 기록. 각 항목에는 범위의 커밋 주제와 구현 세부 사항이 있습니다. 공개 GitHub 저장소는 컴파일된 다운로드 또는 GitHub 릴리스와 함께 소스 코드를 포함.

Git 출처: Git은 v0.6.12 이후에 도입되었습니다. 37개의 소스 커밋은 보존된 소스 ZIP에서 재구성되었습니다. Git 날짜는 원래 빌드 이벤트가 아닌 가져오기를 설명합니다. Christopher Shaw는 커밋 작성자입니다. 공동 작성자 예고편은 해당 빌드 작업에 대해 확인된 모델 기록을 반영합니다. 첫 번째 빌드의 경우 GPT-6 Luna, 나머지 36개의 경우 GPT-6 Sol입니다. 로컬 설치 패키지 및 버전 태그는 초기 GitHub 게시의 일부가 아닙니다.
