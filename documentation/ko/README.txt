설정 파일 편집
--------
모르는 언어, 너무 큰 게임 소리 또는 문제가 있는 음성 때문에 메뉴를 사용하기 어렵다면 게임 밖에서 설정을 바꿀 수 있습니다. 시작 후 모드는 현재 설정을 사용해 Bop It! 게임 폴더 안에 UserData/BopItAccess.ini를 자동으로 만듭니다. 메모장 같은 편집기로 열 수 있는 일반 텍스트 파일입니다.

파일에는 게임의 언어, 음악·효과음·음성 안내 볼륨, 진동, 전체 화면, 해상도와 오디오 지연, 모드의 음성·점자·힌트 등의 설정, 별도로 저장되는 OneCore와 SAPI 음성 설정, 플레이어가 사용하는 게임 및 모드 입력 할당이 포함됩니다. 사용할 수 있는 해상도와 설치된 음성은 주석에 표시됩니다.

편집하기 전에 게임을 종료하세요. 해당 구역에서 기존 항목의 값을 바꾸고 파일을 저장한 다음 게임을 다시 시작하세요. 변경 사항은 실행할 때 읽으며, 게임이 실행 중일 때 바로 적용되지는 않습니다. 게임 메뉴에서 바꾼 설정은 파일에도 자동으로 저장됩니다.

구역 이름과 설정 이름은 모든 언어에서 영어로 유지됩니다. 켜기와 끄기는 On과 Off를 권장하며 True/False, Yes/No, 1/0도 사용할 수 있습니다. 주석에 선택 항목과 범위가 설명되어 있습니다. 누락되거나 잘못된 값은 해당 저장 설정을 그대로 유지하며, 다른 올바른 변경 사항은 적용됩니다. 중복된 입력 할당은 거부됩니다.

주석과 알 수 없는 항목은 유지됩니다. 게임 실행 중 다른 프로그램이 파일을 수정하면 그 편집을 보호하기 위해 모드가 해당 세션의 남은 시간 동안 파일 자동 저장을 중단합니다. 적용하려면 게임을 종료하고 다시 실행하세요. 편집 전에 백업을 남길 수도 있습니다.

음성에 문제가 있으면 OneCore 또는 SAPI 구역에서 Voice=System default로 설정하세요. OneCore 음성은 이름 | 언어 형식을 사용합니다. SAPI는 설치된 음성의 표시 이름이나 전체 레지스트리 ID를 사용할 수 있습니다. 파일에 사용 가능한 선택 항목이 나옵니다. OutputMode=Auto는 실행 중인 지원 스크린 리더, OneCore, SAPI 순으로 시도합니다.

아래 예시는 언어를 영어로 바꾸고 게임 소리를 낮추며 시스템 기본 음성을 사용하는 자동 음성 출력을 복원합니다. 파일에 이미 있는 해당 항목을 수정하세요. 이 내용은 참고용 발췌이며 파일 끝에 추가할 새 구역이 아닙니다. 다른 설정은 그대로 두세요.

[Game]
Language=en
MusicVolume=30
SfxVolume=30
VoiceOverVolume=30

[Mod]
SpeechOutput=On
OutputMode=Auto

[OneCore]
Voice=System default

[SAPI]

AI 사용에 관한 투명성 안내
--------------------

이 모드는 ‘바이브 코딩’으로 만들어졌습니다. 모든 코드는 인공 지능에 의해 완전히 생성되고 연구되었으며, 기본 아키텍처에 대한 인간의 기술적인 이해는 제한적이었습니다. 이 모드를 사용하는 데 따른 책임은 본인에게 있습니다.

즉, 모든 단일 모드 기능과 디자인 결정은 인간에 의해 작성되고 승인되었습니다. 테스트는 결코 자동화되지 않았습니다. 실제 인간 플레이어와 테스터가 신중하고 광범위하게 수행했습니다.

참고: 다국어 텍스트와 문서는 AI에 의해 생성되었으며 원어민이 검토하지 않았습니다. 높은 번역 부정확성이 예상됩니다. 에이전트 코딩이 없었다면 이 프로젝트는 존재하지 않았을 것입니다. 기회를 주셔서 감사합니다!

MelonLoader 시작 창
---------------------------

제공된 Loader.cfg 템플릿은 MelonLoader의 별도 시작 화면과 콘솔을 숨깁니다. 설치 프로그램은 게임을 시작해야 하는 알파 빌드 준비 전에 동일한 두 가지 기본값을 자동으로 적용합니다. 이 설정은 게임의 제목 화면이나 모드의 시작 화면을 건너뛰지 않습니다.

게임을 종료한 상태에서 게임 폴더의 UserData/Loader.cfg를 엽니다. 파일이 이미 있다면 기존 [loader] 섹션의 disable_start_screen 값을 true로, 기존 [console] 섹션의 hide_console 값을 true로 설정합니다. 다른 항목은 변경하지 마세요. 파일이 없다면 빌드에 포함된 UserData/Loader.cfg 템플릿이나 소스 코드의 configuration/Loader.cfg를 복사합니다. 기존 Loader.cfg 파일을 템플릿 전체로 덮어쓰지 마세요.

[loader]
disable_start_screen = true
