Bop It Access 0.9.0 使用以下第三方运行时库：

0Harmony.dll - Harmony 单独安装提供的补丁库
MelonLoader. Bop It Access 用它来观察游戏设置何时完成
在第一次运行 mod 时加载。源安装包和本地安装包都没有
包含此 DLL；请参阅 MelonLoader 随附的通知。

prism.dll — Prism 屏幕阅读器和文本转语音抽象库
伊森·杜普伊 (Ethan Dupuy) 和贡献者。当前的 Windows x64 mod 使用 Prism
语音和盲文输出。
项目及来源： https://github.com/ethindp/prism
许可证：Mozilla 公共许可证，版本 2.0。
许可证文本： https://github.com/ethindp/prism/blob/master/LICENSE

此源存储库不包含本机 Prism DLL。
它还包括未编译的 Bop It Access DLL。
构建者必须单独获取或构建兼容的 Windows x64 prism.dll。
Bop It Access 在运行时动态加载 Prism。

早期的 mod 版本使用 Tolk.dll 和 nvdaControllerClient64.dll。
准备好的本地安装包包含这些 DLL 及其适用的
许可文本。这些软件包不是 GitHub 版本，也不属于此版本
源存储库。当前的 mod 不再需要这些 DLL。

翻译创作工具（游戏运行时不需要或捆绑）：

Argos Translate 及其语言模型离线使用来准备草稿
mod 演讲目录和项目文件的翻译。上游
项目获得 MIT 或 CC0 双重许可；其型号包如下提供
相同的条款。项目： https://github.com/argosopentech/argos-translate
麻省理工学院许可证： https://github.com/argosopentech/argos-translate/blob/master/LICENSE

经项目业主批准，使用谷歌翻译来改进
机器翻译的草稿。创作期间发生翻译请求；
该模组在运行时不会联系谷歌或需要互联网连接。

Beautiful Soup 4 用于在准备时保留 HTML 结构
翻译的指南。它是 MIT 许可的，不是 mod 运行时的一部分。
项目及许可信息： https://www.crummy.com/software/BeautifulSoup/
