欢迎

欢迎使用 Bop It Access！无论这是您的第一个 Bop It 游戏、您的第一个视频游戏，还是您已经喜欢的游戏，这里都欢迎您。本指南从基础知识开始，并在您遇到该模组的功能时解释它们。您可以使用上面的内容直接跳到主题。

一个 键盘 是计算机上的一组按键。一个 控制器 是一款手持游戏手柄。本指南提到 Xbox 按钮名称的地方，它们只是示例：另一个控制器可能对同一按钮位置使用不同的标签。一个 菜单项 是一个选择，例如“播放”或“设置”。该项目与 焦点 是您下一次确认时将激活的。

什么是 Bop It!？

Bop It! The Video Game 将 Bop It 节奏和反应游戏带到电脑上。语音会发出命令，您可以在时间用完之前进行匹配的输入。在经典难度下，主要命令是 拍打, 扭转, 和 拉动。极端难度也增加了 转动 和 拨动。命令变得更快，因此随着回合的进行，聆听和计时变得更加重要。该游戏提供单人、组队、传球和一对一游戏，有四个视觉和音乐阶段：Shapes、Space、City和Office。 官方Steam页面 介绍了游戏，以及 官方游戏说明 解释其模式。

当您听到命令时，请使用指定的控件。例如，在默认键盘上，拍打 是 Space。您可以在 控制参考。您不必在开始之前记住所有内容：模组可以说出菜单上的按钮提示，并且您可以根据需要请求提示。

什么是 Bop It Access？

Bop It Access 是针对 Steam 上的 Windows x64 版《Bop It!》制作的非官方模组。它为菜单和结果提供语音与盲文输出，还增加了四个关卡的按需说明、额外控制方式和帧率限制等设置。模组旨在方便玩家操作，同时保留游戏原有的语音指令和节奏。

本模组通过 MelonLoader 加载，并使用 Prism 输出语音和盲文。您仍需要拥有游戏本体。 自动模式优先使用正在运行的兼容屏幕阅读器，其次使用 OneCore，最后使用 SAPI。

该模组的菜单和公告遵循游戏的语言设置。它包括英语、法语、意大利语、德语、西班牙语（西班牙）、西班牙语（拉丁美洲）、日语、韩语、简体中文和巴西葡萄牙语。

无障碍功能

  • 标题屏幕、主菜单、播放和歌曲选择、设置和控制、模组设置、音频校准、排行榜、游戏内成就簿、制作人员名单、暂停菜单和结果屏幕的语音。
  • 公布焦点按钮、滑块、切换开关、名称、值和更改的值。可选的索引、控件类型标签、滑块范围和朗读格式优化让您可以调整细节。
  • 游戏结束时得分或获胜者演讲，然后是排队的菜单演讲，以及仅在结果屏幕上的“阅读得分”快捷方式。
  • 四个阶段描述，在比赛开始前根据歌曲选择屏幕的要求进行朗读。
  • 游戏当前模式和难度的教程参考，根据歌曲选择的要求以及每个动作当前指定的控制进行朗读。一对一包括 拍打 输入。
  • 可选的一对一颜色和生命计数公告。
  • 键盘、控制器或两者的按钮提示，具有可调节的时间、重复次数和按需发言提示快捷方式。
  • Prism 支持通过屏幕阅读器、OneCore 和 SAPI 输出语音，并可通过兼容的屏幕阅读器输出盲文。
  • 键盘和控制器重新映射多个本机和 mod 控件，包括排行榜过滤器和语音快捷方式。
  • 已保存的主语音开关，带有用于重新打开语音的语音指令。
  • 游戏语言设置提供的每种语言的语音和游戏内用户指南。

便利功能

  • 已保存的限制 FPS 设置，具有 30、60、120、240 和无限制选项。默认值为 60。
  • 当游戏窗口位于后台时，用于静音游戏音频或模组语音的单独选项。
  • 更改语音输出快捷方式，可在与 Mod 设置菜单相同的模式之间循环。
  • 保存游戏会话中的偏好设置，包括语音输出、盲文、提示和帧速率上限。
  • 更多控件可用于在游戏自己的控件菜单中重新映射，并且拒绝重复分配。

注意事项与限制

  • 在回合开始前要求提供描述。 该模组故意不在游戏进行过程中叙述场景。玩家必须听到游戏的口头命令并做出反应；额外的旁白可以涵盖命令并结束回合。
  • 自动模式依次优先使用运行中的屏幕阅读器、OneCore 和 SAPI。已安装的语音和系统会影响响应速度。模组不会安装额外语音。
  • 一些本机控件仍然是固定的。 该模组极大地扩展了游戏的控制菜单，但它并没有使每个游戏输入都可以重新映射。
  • 帧速率影响输入轮询。 FPS限制器可以大幅降低系统负载。它不会故意减慢动画速度或改变游戏时间，但游戏在较低 FPS 时检查基于帧的输入的频率较低。较高的设置可以提供更准确的输入计时，尤其是在快速回合中。
  • Windows x64 是当前的 mod 平台。 Prism支持其他平台，可能有助于以后的开发。此版本的游戏集成、构建参考和安装步骤适用于 Windows x64。
  • 翻译需要审核。 最初的非英语模组文本和指南是机器翻译的。某些措辞、游戏术语和输入名称可能需要流利的说话者进行纠正。请报告任何不清楚或不准确的内容。

购买游戏并检查电脑配置

购买 Bop It! The Video Game 于 Steam。如果 Steam 对您来说是新号码， 安装Steam，创建或登录帐户，从商店页面购买游戏，然后从 Steam 库安装游戏。的 Steam 入门指南 涵盖了这些步骤。游戏的购买与此模组是分开的。

购买或安装前，请检查 Steam 页面上的当前最低系统要求。在撰写本指南时，其 Windows 最低配置包括 Windows 10 64 位、Intel i5-4460 或 AMD FX-6300、8 GB 内存、具有 2 GB 视频内存的图形处理器和 2 GB 存储空间。该页面还表示排行榜需要互联网连接。要求可能会发生变化，因此 Steam 的列表是最终参考。

我们仍然欢迎您在低于游戏最低要求的计算机上尝试并报告问题。但是，如果问题是由不符合规格的系统引起的，则无法保证修复。

获取并安装模组

安装人员状态： 已经构建了 Windows 安装程序预览用于本地测试，其源代码包含在项目中。尚未发布公共编译的安装程序或 mod 版本。观看 Bop It Access 项目页面 供公众下载。使用下面的源路径或项目直接提供的预览。

当前安装路径：从源构建

公共 GitHub 存储库当前包含源代码和文档，没有编译的下载或 GitHub 版本。构建意味着将源文件转换为 mod 的 DLL。的 存储库的构建说明 是维护的参考。以下是用日常语言表达的完整当前路线：

  1. 通过 Steam 在 Windows x64 上安装游戏。如果您没有使用默认位置，请从 Steam 的库中找到其文件夹。
  2. 随着比赛结束， 安装MelonLoader 进入该游戏文件夹。该游戏的开发使用了 x64 MelonLoader 0.7.3 Open-Beta；其他组合尚未验证。启动游戏一次并再次关闭。这让 MelonLoader 准备 mod 所需的文件。
  3. 安装包含 .NET 6 定位包的 .NET SDK。 下载或克隆 Bop It Access 源，在包含其的文件夹中打开PowerShell README.md，然后运行以下命令。如果您的 Steam 库位于其他位置，请更改示例游戏路径。
$gameDir = 'C:\Program Files (x86)\Steam\steamapps\common\Bop It!'
dotnet build .\src\BopItAccess.csproj -c Release "-p:BopItGameDir=$gameDir"
  1. 游戏关闭后，复制构建的文件 src\bin\Release\net6.0\BopItAccess.dll 进入游戏的 Mods 文件夹。如果需要，创建该文件夹。复制构建的 src\bin\Release\net6.0\documentation 文件夹也放到游戏文件夹里。它包含本指南及其链接所需的配套文档。
  2. 从 Prism 发布页面获取适用于 Windows x64 的官方 Prism v0.18.3 prism.dll，或从源代码构建相同版本。将 prism.dll 放在游戏主文件夹中，与游戏可执行文件放在一起，不要放进 Mods 文件夹。
  3. 如果使用屏幕阅读器，请先启动它，再启动游戏。没有运行兼容的屏幕阅读器时，Prism 优先使用 OneCore；如果 OneCore 不可用，则使用 SAPI。

一个常见的 Steam 位置是 C:\Program Files (x86)\Steam\steamapps\common\Bop It!。如果您选择不同的 Steam 图书馆，您的位置可能会有所不同。如果您有项目中本地提供的安装 ZIP，请关闭游戏并将其内容解压到游戏文件夹中，从而允许 Mods 要合并的文件夹。这些本地包与纯源代码 GitHub 存储库是分开的。

MelonLoader 启动窗口

提供的 Loader.cfg 模板隐藏了 MelonLoader 的单独启动屏幕和控制台。在需要启动游戏的任何 alpha 构建准备之前，安装程序会自动应用相同的两个默认值。这些设置不会跳过游戏的标题屏幕或模组的欢迎屏幕。

关闭游戏后，打开游戏文件夹中的 UserData/Loader.cfg。如果文件已经存在，请在现有的 [loader] 节中将 disable_start_screen 设为 true，在现有的 [console] 节中将 hide_console 设为 true。保留其他所有设置。如果文件不存在，请复制构建文件中提供的 UserData/Loader.cfg 模板，或源码中的 configuration/Loader.cfg。切勿用整个模板覆盖已有的 Loader.cfg。

[loader]
disable_start_screen = true

[console]
hide_console = true

该模组不会在每次启动时重置这些选项。如果您需要加载程序的窗口进行故障排除，您可以手动将任一值更改回 false。仅当安装程序的真实值仍然存在时，安装程​​序卸载才会恢复原始值，并保留其他加载程序配置编辑。

使用提供的安装程序预览

关闭游戏，运行安装程序，并批准Windows’管理员提示。它在可用驱动器中搜索 Steam 个库。如果需要，请使用“浏览”选择游戏文件夹。它的状态字段是只读的：使用 Tab 键切换到它并使用光标键或选择并复制文本来查看其操作。进度条报告当前步骤。

如果存在最新的公共模组版本，安装会下载该版本。在此之前，仅当您愿意测试最新源时才使用 Install alpha：确认其警告，让它准备缺少的依赖项并编译 mod，然后等待成功消息。 alpha路线可能会打开游戏准备构建参考；当询问时关闭该游戏窗口，以便安装程序可以继续。

安装程序根据需要获取官方 MelonLoader 0.7.3、Prism 0.18.3 和便携式 .NET 6 SDK。它使用上面显示的两个配置标志隐藏 MelonLoader 自己的开始屏幕和控制台。更新使用 GitHub，无需新下载的安装程序。中止请求确认并撤消安装的更改。

可以在安装程序和 Windows 已安装的应用程序中进行卸载。它删除拥有的 mod 文件和 Bop It Access 首选项，包括 UserData/BopItAccess.ini 及其临时文件。它保留了本机游戏首选项、不相关的模组和 .NET SDK。加载程序配置清理仅恢复安装程序未更改的目标标志，保留其他编辑。如果清理无法完成，状态日志和完成消息会报告该情况。

首次启动

  1. 如果使用屏幕阅读器，请先启动它。安装 MelonLoader、模组 DLL 和 prism.dll 后，通过 Steam 启动 Bop It!。
  2. 在您第一次使用该模组时，游戏的音乐、SFX 和 Voice Over 音量从 30 开始。如果您要升级，您保存的游戏音频级别将保持不变。
  3. 等待公告： Bop It Access 演讲已准备就绪。游戏仍在加载中。在使用控件之前，请等待标题屏幕或主菜单公告。 该模组在游戏完成加载之前就已准备就绪。

编辑设置文件

如果陌生语言、过大的游戏音量或有问题的语音让菜单难以操作，你可以在游戏外修改设置。启动完成后，模组会根据当前设置，在 Bop It! 游戏文件夹内自动创建 UserData/BopItAccess.ini。这是普通文本文件，可以用记事本等编辑器打开。

文件包含游戏语言、音乐音量、音效音量、语音提示音量、振动、全屏、分辨率和音频延迟；模组的语音、盲文、提示等设置；分别保存的 OneCore 和 SAPI 语音设置；以及面向玩家的游戏和模组操作绑定。可用分辨率和已安装语音会列在注释中。

编辑前请关闭游戏。找到对应分区，修改已有条目的值，保存文件，然后重新启动游戏。修改在启动时读取，不会在游戏运行期间立即生效。通过游戏菜单修改的设置会自动同步到文件。

无论使用哪种语言，分区名称和设置名称都保持英文。开关建议使用 On 和 Off，也支持 True/False、Yes/No 和 1/0。注释会说明选项和范围。缺失或无效的条目会保留对应的已保存设置，其他有效修改仍会生效。重复的操作绑定会被拒绝。

注释和未知条目会保留。如果其他程序在游戏运行期间修改文件，模组会在本次会话剩余时间内停止自动写入，以保护这些编辑。请关闭并重新启动游戏，让修改生效。编辑前也可以保留备份。

如果某个语音有问题，请在 OneCore 或 SAPI 分区中设置 Voice=System default。OneCore 使用名称 | 语言格式；SAPI 支持已安装语音的显示名称或完整注册表 ID。文件中会列出可用选项。OutputMode=Auto 会依次尝试正在运行的受支持屏幕阅读器、OneCore 和 SAPI。

各模式详细指南

所有四种模式都首先选择歌曲/舞台并选择经典或极限。舞台会改变您所看到和听到的内容，而命令会告诉您要进行哪些输入。 Classic 要求 拍打、扭转 和 拉动。Extreme 还可以要求 转动 和 拨动。当游戏说出命令时，请在时间窗口结束之前按下指定的输入。您可以在玩之前在“设置”>“控制”中查看或更改分配。在成功的跑步过程中，节奏会加快，因此没有固定的最后一首歌曲要到达的部分。这些规则来自于 官方游戏说明 以及游戏当前的得分和结果屏幕。

独奏

独奏是学习节奏最简单的地方。每个口头命令都有一个人响应。如果游戏显示 拍打，请使用您的 拍打 输入；如果显示 扭转 或 拉动，请改用该输入。在 Extreme 中，也要准备好 转动 和 拨动。随着命令变得更快，继续前进。

评分： 每个正确的反应都会为正在进行的跑步加一分。分数是您成功回复的次数。错误或错过的反应，包括反应太迟的反应，都会导致该轮运行结束。最终结果屏幕显示您的数字分数。该模组会在读取重播、排行榜或返回之前宣布它。您可以按“阅读乐谱”再次收听。当本地、好友和全球排行榜视图可用时，单人得分也可能会显示在这些视图中。

如何重新开始： 在结果屏幕上选择“重播”，或返回并选择其他模式或歌曲。重播是一次新的比赛；您之前的成绩仍然可以在游戏记录的排行榜上进行比较。

派对

聚会是一群人轮流进行的。每个人都玩 他们自己的 run，响应与 Solo 相同类型的调用命令。当一个人的跑步结束时，游戏可以要求一个名字附加到该分数上。继续查看会话的政党排行榜，然后让下一个人轮流。这是一种比较运行的友好方式，无需每个人立即采取行动。

评分： 成功的响应会建立该玩家的数字跑分。错误、错过或迟到的命令会结束他们的奔跑，最终得分属于该玩家。会话排行榜列出了姓名、排名和分数，以便小组可以比较结果。游戏不强制规定单一的正式获胜者；您的团队可以决定什么才算获胜。该模组会在游戏结束时读取分数，然后读取下一个菜单选项，并说出队伍名称和排行榜步骤。

如何继续玩： 当出现提示时使用“继续”，在出现提示时选择或确认名称，然后按照游戏进行到下一个玩家或得分视图。如果重玩，则会开始另一轮得分比赛，而不是延长刚刚结束的比赛。

通过它

通过这是一个共同的挑战。一名玩家响应命令，直到游戏调用 通过它！ 接到电话后，立即将控制器交给下一个人。下一位玩家继续 一样 连胜。接到通知后继续通过并继续回答游戏的 Bop It 命令。当每个人都知道谁是下一个接收控制器并且有足够的空间安全地通过它时，此模式效果最佳。

评分： 正确的回答会延续一个共享的数字分数，而不是为每个人开始一个新的分数。因错过命令而中断连胜的人结束该回合。结果屏幕显示最终的共享分数，模组会自动说出该分数，并且可以通过阅读分数重复该分数。分数告诉你该小组走了多远；在此模式下，并不是个人玩家的排名。

如何重试： 选择“重播”开始新的共享连胜，或选择“返回”留下结果。

一对一

一对一让两名玩家， 黄色 和 绿色，进入同一轮。每个都以 三个生命。黄色响应扭转和拉动；格林回应 转动 和 拨动。 拍打 是一场共享竞赛：两名玩家都应该做好准备，第一个击中 拍打 的人会获得一条生命，最高可达游戏的三条生命限制。游戏为一些变化提供了微妙的声音。当“设置”>“模组设置”>“一对一反馈”（默认）打开时，模组会宣布开始或更改的活动颜色以及失去或获得后的生命数。 获得生命时，会朗读玩家颜色和新的总数。失去生命时，保持原来的方式，只朗读剩余数量。

一轮如何结束： 错过所需的命令会让负责的玩家丧命。第一个生命值为零的玩家失败，其他颜色的玩家获胜。与 Solo、Party 和 Pass It 不同，结果是 获胜者，而不是数字最终分数。该模组会在游戏结束时宣布获胜颜色；当结果屏幕可见时，读取分数会重复该结果。可选的生命公告仅适用于此模式。

一起准备： 在开始之前先商定哪个人是黄色的，哪个人是绿色的。如果您要共享一台输入设备，请检查当前的“控制”屏幕，尤其是第二个 拍打 分配。一对一的比赛速度很快，因此一轮练习可以帮助双方球员学习控制能力。
