Bop It Access：技术构建历史

按时间顺序记录从 v0.1.0 到 v0.9.11 的 58 个模组构建版本，以及独立的安装程序预览。每个条目都有范围变更摘要和实施详细信息。公共 GitHub 存储库包含源代码，尚未编译下载或 GitHub 版本。

Git 出处： Git 是在 v0.6.12 之后引入的。 37 个源提交是根据保留的源 ZIP 重建的；他们的 Git 日期描述了导入，而不是原始构建事件。 Christopher Shaw 是提交作者。合著者预告片反映了相应构建工作的经过验证的模型记录：第一个构建为 GPT-6 Luna，其余 36 个构建为 GPT-6 Sol。本地安装包和版本标签不是初始 GitHub 发布的一部分。
