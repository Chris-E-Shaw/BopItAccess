Welcome

Welcome to Bop It Access! Whether this is your first Bop It game, your first video game, or a game you already love, you are welcome here. This guide starts with the basics and explains the mod's features as you encounter them. You can use the contents above to jump straight to a topic.

A keyboard is the set of keys on your computer. A controller is a handheld gamepad. Where this guide mentions Xbox button names, they are examples: another controller may use different labels for the same button position. A menu item is a choice such as Play or Settings. The item with focus is the one your next confirm press will activate.

What is Bop It!?

Bop It! The Video Game brings the Bop It rhythm and reaction game to a computer. A voice calls commands, and you make the matching input before time runs out. In Classic difficulty the main commands are Bop, Twist, and Pull. Extreme difficulty also adds Spin and Flick. The commands get faster, so listening and timing matter more as a round goes on. The game offers Solo, Party, Pass It, and One-on-One play, with four visual and musical stages: Shapes, Space, City, and Office. The official Steam page introduces the game, and the official game description explains its modes.

When you hear a command, use its assigned control. For example, on the default keyboard, Bop is Space. You can find every default in the control reference. You do not have to memorize everything before starting: the mod can speak button hints on menus, and you can request a hint on demand.

What is Bop It Access?

Bop It Access is an unofficial, independent mod for the Windows x64 Steam version of the game. A mod is an optional addition that changes how a game behaves. This one adds speech and braille support for menus and results, on-demand descriptions of the four stages, extra controls, and useful settings such as a frame-rate limit. It aims to make the game easier to navigate while leaving its spoken gameplay cues and timing intact.

The mod uses MelonLoader to load into the game. It uses Prism for speech and braille output through supported screen readers and speech engines. When no supported screen reader is running, Prism prefers Windows OneCore speech and then SAPI. The mod does not replace the game, and you still need your own copy of Bop It!.

The mod follows the game's Language setting for its menus and announcements. It includes English, French, Italian, German, Spanish (Spain), Spanish (Latin America), Japanese, Korean, Simplified Chinese, and Brazilian Portuguese.

This mod is vibe-coded. All code was completely generated and researched by artificial intelligence, with limited technical human understanding of its underlying architecture. Please use this mod at your own risk.

That being said, every single mod feature and design decision was authored and approved by humans. Testing was never automated; it was carefully and extensively performed by real human players and testers.

Accessibility features

  • Speech for the title screen, main menu, Play and song selection, Settings and Controls, Mod Settings, audio calibration, leaderboards, the in-game achievements book, credits, pause menu, and result screens.
  • Focused buttons, sliders, toggles, names, values, and changed values are announced. Optional indexing, control-type labels, slider ranges, and speech formatting let you tune the detail.
  • Score or winner speech at game over, followed by queued menu speech, plus a Read Score shortcut on the results screen only.
  • Four stage descriptions, spoken on request from the song-selection screen before play begins.
  • The game's tutorial reference for the current mode and difficulty, spoken on request from song selection with each action's current assigned control. One-on-One includes both Bop inputs.
  • Optional One-on-One colour and life-count announcements.
  • Button hints for keyboard, controller, or both, with adjustable timing, repetitions, and an on-demand Speak Hints shortcut.
  • Screen-reader and speech-engine output through Prism, optional braille output, and configurable OneCore or SAPI system speech.
  • Keyboard and controller remapping for several native and mod controls, including leaderboard filters and speech shortcuts.
  • A saved master speech switch with spoken instructions for turning speech back on.
  • Speech and an in-game user's guide in every language offered by the game's Language setting.

Quality of life features

  • A saved Limit FPS setting with 30, 60, 120, 240, and Unlimited options. The default is 60.
  • Separate options to mute game audio or mod speech when the game window is in the background.
  • A Change Speech Output shortcut that cycles through the same modes as the Mod Settings menu.
  • Saved preferences across game sessions, including speech output, braille, hints, and the frame-rate cap.
  • More controls available for remapping in the game's own Controls menu, with duplicate assignments rejected.

Notes and limitations

  • Descriptions are requested before the round. The mod intentionally does not narrate scenery during active gameplay. A player must hear and react to the game's verbal commands; extra narration could cover a command and end the round.
  • Stage descriptions still need visual review. The descriptions of all four stages have not been verified for accuracy by a sighted user or player. They still need visual review and confirmation.
  • OneCore and SAPI are available speech engines. Auto prefers a supported running screen reader, then OneCore, then SAPI. Your installed voices and system can affect response time. For non-English speech, choose a voice for the active engine that supports your selected game language; the mod does not install additional voices.
  • Some native controls are still fixed. The mod greatly expands the game's Controls menu, but it does not make every game input remappable.
  • Frame rate affects input polling. The FPS limiter can sharply reduce system load. It does not deliberately slow animations or change game timing, but the game checks frame-based input less often at lower FPS. A higher setting can give more accurate input timing, especially in fast rounds.
  • Windows x64 is the current mod platform. Prism supports other platforms, which may help future development. This release's game integration, build references, and installation steps are for Windows x64.
  • Translations need review. The initial non-English mod text and guides were machine translated. Some wording, game terms, and input names may need correction from fluent speakers. Please report anything unclear or inaccurate.

Using the supplied installer

Close Bop It!, open BopItAccess-Installer.exe and approve the Windows administrator prompt. The installer looks for the game in Steam libraries on all available drives. The Welcome and controls text field receives focus first and contains the instructions you can return to with Alt+W. Check the displayed Game folder; use Browse if you need to choose another folder. Tab moves between controls. Alt+L returns to the changing Status log, where you can review messages with the arrow keys, select text and copy it.

Installer 1.0 briefly requests foreground activation and keyboard focus. If its bounded startup observation ends with another window still active, it flashes its title and taskbar button and asks you to use Alt+Tab to switch to the installer. Activate the installer before using its keyboard or controller controls. Alt+G focuses the game-folder field.

Show advanced is unchecked when the installer opens. It reveals Install alpha, Save diagnostics and Copy diagnostics. Install downloads the latest stable public release. Install alpha is optional: it asks for confirmation, downloads the latest experimental source and builds it on your computer. Update appears when a newer public release is found for an installed copy.

Status messages explain what is downloading, installing or finishing in plain language. One progress bar shows estimated progress for the whole installation, without resetting for each download or file. It advances in five-percentage-point increments; some preparation stages may take time without a visible change. A newly available update and confirmation that diagnostics were copied are sent through Windows accessibility notifications to your screen reader. Whether these are spoken depends on your screen reader and its Windows notification support.

Installer 1.0 never launches Bop It! during installation. Alpha reuses matching local build files or prepares temporary files from your own installed game while it stays closed. The installer then places MelonLoader in the game folder and immediately adds Mods/BopItAccess.dll, followed by Prism, settings, the complete documentation and uninstall support. Wait for the success message, then launch the game yourself through Steam when you are ready.

After a successful installation, Play Bop It! The Video Game appears. Activate it to launch the game yourself through Steam when you are ready. The installer never starts the game automatically during installation.

A compiled release needs the Windows x64 .NET 6 runtime, not a development SDK. Existing complete runtimes are reused. A missing runtime is downloaded from Microsoft and placed in MelonLoader/Dependencies/dotnet. Install alpha also needs a compatible .NET SDK and the .NET 6 targeting pack: an existing SDK is reused or Microsoft’s official SDK is installed system-wide. The installer creates no new SDK folder in the game root. MelonLoader 0.7.3 Open-Beta and Prism 0.18.3 come from their official releases. Shared Microsoft .NET components and SDKs remain installed after abort or uninstall.

Quit closes the installer. If installation is still running, it asks whether to abort and undo the installation before closing; Keep open continues normally. If installation finishes while you are deciding, the dialog updates to say that it is finished, and Quit does not undo the completed installation. Uninstallation, once removal begins, finishes safely before quitting. Abort also asks for confirmation and reverses this attempt’s game-file changes. Canceling during Microsoft .NET setup waits for that shared-component installation to finish safely.

After confirming Uninstall, choose Uninstall for me or Uninstall for everyone. Both remove the shared mod files from this game folder, so the mod will no longer be available to anyone using that installation. The choice controls whose saved Windows mod preferences are removed: your requesting account only, or every local Windows profile, including signed-out profiles. Preferences belonging to the original game are kept. The .NET SDK remains installed.

When the installer removes its own MelonLoader installation and no other mods need it, it also removes the known Loader.cfg and MelonPreferences.cfg files and the empty Plugins, UserLibs and UserData folders. Bop It Access settings, known logs, guides and installer files are removed. Other mods, pre-existing shared loader files and unrecognised files are protected. This also means an unknown file can leave a folder behind; the installer reports that in diagnostics rather than deleting unrelated data.

The installer stays open after uninstall so you can review the result, save diagnostics or install again. Choose Quit when finished. The running uninstall helper and automatic diagnostic files are cleaned up after the window closes. A reinstall in the same window starts a fresh installation record; delayed cleanup cannot remove the new installation.

Windows Installed Apps uses the same confirmation, preference choice and cleanup. The installer supplies BopItAccess-uninstall.ps1 in the game folder as a shortcut to the installed uninstaller; the compiled ZIP and source builds also include this script. A manually copied script does not install the uninstaller itself. For an older manual installation without an ownership record, the installer removes identifiable mod files and keeps shared files whose origin cannot be established.

If cleanup cannot finish safely, the installer explains that and keeps the information needed to retry. For a managed installation, its Windows uninstall entry and cleanup checkpoint remain until removal succeeds. An older manual copy has no durable ownership record; retry its warnings in the open installer. Do not install, update or remove the mod while Bop It! is running.

Using a controller in the installer

The installer supports Xbox-style controllers and other controllers that Windows exposes through XInput. Its controls are separate from the game’s remappable controls. The D-pad or left stick moves between controls; when a text field is focused, directions review its text instead. The bumpers always move to the previous or next focusable control. A activates the focused button or checkbox. Controller input is handled only while this installer or one of its own dialogs is in the foreground.

B goes back or cancels a dialog; on the main installer window it asks to abort an active installation, otherwise it follows Quit. Start follows Quit on the main window and goes back in a dialog. Y (the top face button) selects all text when an installer text field is focused. Outside text fields on the main window, Y toggles Show advanced. In the status log or another installer text field, the D-pad or left stick works like the arrow keys: Left/Right moves by character and Up/Down by line. Hold LT as Ctrl: Left/Right moves by word and Up/Down by paragraph. Hold RT as Shift to extend the selection; hold LT and RT together to select words or paragraphs. X copies only the selected text; select the part you want first. Keyboard Ctrl+C continues to copy the selection. When no text is selected, the installer also sends accessibility notifications for the character, word, line or paragraph at the caret. The installer sends accessible confirmation when text is copied and reports an empty selection or copy failure. Whether this is spoken depends on your screen reader’s Windows notification support. Controller navigation in Windows’ native folder and save dialogs still needs human verification. A keyboard remains available for entering a folder or filename. Controllers without XInput support are not covered by this implementation.

The separate Welcome and controls text field lists the controller text-review shortcuts; use Alt+W to return to it and Alt+L for the changing Status log. Both fields are read-only, selectable and reviewable. Changing Show advanced announces checked or unchecked. Selecting all confirms success or an empty field. Manually install Bop It Access

This option lets you install the compiled mod without running the Bop It Access installer. You need your purchased Windows x64 game, MelonLoader 0.7.3 Open-Beta, x64, and the .NET 6 Windows x64 runtime. A .NET SDK is not needed. The compiled ZIP does not include MelonLoader or .NET.

MelonLoader · .NET 6 Windows x64 runtime

  1. Install Bop It! through Steam. Find its installation folder from Steam's Library using the option to browse installed files. Close the game.
  2. Install MelonLoader 0.7.3 Open-Beta, x64 into that game folder, and install the .NET 6 Windows x64 runtime if needed. You do not need to start the game before adding the mod.
  3. Download and extract BopItAccess-v1.0.zip. Open the extracted folder, select all its contents, and copy and paste them into the game folder, alongside BopIt!.exe. Agree to merge folders and replace files when asked. There is no need to copy each file separately.
  4. Start your screen reader if you use one, then launch Bop It! through Steam. On this first launch, MelonLoader may download support files and prepare game assemblies. Keep the game open and wait for the mod's startup announcement, followed by the title, welcome or main-menu announcement, before using the controls.

To update a manual installation, close the game and copy all the contents of the newer compiled ZIP into the same game folder again, merging folders and replacing files when asked. The ZIP does not contain your saved UserData/BopItAccess.ini game and mod settings.

A manual installation does not register a Windows uninstaller. Its BopItAccess-uninstall.ps1 file is a shortcut to an installer-managed uninstaller and cannot create one by itself. To disable the manually installed mod, remove Mods/BopItAccess.dll. For full removal, use the installer's Uninstall option; it can identify an older manual copy, offer preference cleanup and protect unrelated files. If removing files yourself, remove only this mod's files and keep any shared files another mod needs.

MelonLoader startup windows

The ZIP includes a MelonLoader configuration file that hides its separate start screen and console. The installer applies the same defaults. These settings do not skip the game's title screen or the mod's welcome screen.

If you want those windows visible for troubleshooting, close the game and open UserData/Loader.cfg in the game folder. Change disable_start_screen under [loader] and hide_console under [console] to false. The mod does not reset these choices on each launch.

Advanced: build from source

The GitHub Source code archives and repository contain source, not a ready-to-install DLL. Building requires the SDK and generated game references described below. The supplied installer’s Install alpha route prepares references without launching the game; the manual source route below uses a previous MelonLoader game launch.

  1. Install the game through Steam on Windows x64. Find its folder from Steam's Library if you did not use the default location.
  2. With the game closed, install MelonLoader into that game folder. Development has used x64 MelonLoader 0.7.3 Open-Beta with this game; other combinations are not yet verified. Start the game once and close it again. This lets MelonLoader prepare the files the mod needs.
  3. Install a .NET SDK that includes the .NET 6 targeting pack. Download or clone the Bop It Access source, open PowerShell in the folder containing its README.md, and run the command below. Change the example game path if your Steam library is elsewhere.
$gameDir = 'C:\Program Files (x86)\Steam\steamapps\common\Bop It!'
dotnet build .\src\BopItAccess.csproj -c Release "-p:BopItGameDir=$gameDir"
  1. With the game closed, copy the built file src\bin\Release\net6.0\BopItAccess.dll into the game's Mods folder. Create that folder if needed. Copy the build's src\bin\Release\net6.0\documentation folder into the game folder too. It contains this guide and the companion documents its links need.
  2. Obtain the official Windows x64 Prism v0.18.3 prism.dll from the Prism releases, or build the matching version from source. Place it beside the game's executable, in the main game folder, not inside Mods.
  3. Start your screen reader if you use one, then launch the game through Steam. Without a compatible running screen reader, Prism prefers OneCore speech and falls back to SAPI if needed.

Save before an installation or uninstall trial so your recording survives automatic-log cleanup. Logs may contain Windows usernames and full paths: review them before sharing. Deliberately exported copies remain after uninstall.

Your first launch

  1. Start your screen reader if you use one. Launch Bop It! through Steam after installing MelonLoader, the mod DLL, and prism.dll.
  2. On the first manual launch after installing MelonLoader, it may download support files and generate game assemblies. Allow about a minute, or longer on some systems. The mod cannot speak until MelonLoader finishes loading it. Keep the game open and wait for the Bop It Access startup announcement, then for the title-screen or menu announcement before using the controls.
  3. On your first-ever use of the mod, the game's Music, SFX, and Voice Over volumes start at 30. If you are upgrading, your saved game audio levels stay as they were.
  4. Wait for the announcement: Bop It Access speech is ready. The game is still loading. Wait for the title screen or main menu announcement before using the controls. The mod becomes ready before the game finishes loading.
  5. Wait several more seconds for the title screen announcement. Inputs may do nothing during loading. Press Bop (Space by default, or your controller's confirm button) to move on from the title screen. On your first launch with the welcome feature, the welcome screen takes focus before the main menu. Move with Up/Down and confirm with Enter, Space, or controller confirm.
  6. If you previously turned speech off, the saved setting stays off. The mod gives a spoken recovery message at startup with the current keyboard and controller binding for Toggle Speech. By default, press F8 or controller Select to turn it on again.
  7. Choose open mod settings, recommended on the welcome screen to configure speech, braille, and hints first. Choose Read user's guide to read this document in the game, or Continue to game to reach the main menu.

Welcome screen

The introductory message is itself a focusable item above the three choices. Move back up to hear the whole message again. It names both of your current Speak Hints bindings, even if Hints Type is set to show just one device. The example below uses the default bindings; the game announces your current assignments.

Welcome message. Welcome to Bop It Access! Thank you for installing this project. Hints for every screen, including this one, are available at any time by pressing H on your keyboard, or Right Stick click on your controller. Before playing, feel free to visit Mod Settings to customize your experience, or jump right in with the defaults. A full user's guide is also built right in if you'd like additional help. What would you like to do?

The welcome screen is marked complete only after one of its choices opens the selected destination. If the game closes while you are still on the welcome screen, it appears again next launch. To see it again after completing it, use Settings > Mod Settings > Reset Welcome Screen; the reset takes effect on the next launch.

Languages

In the game's Settings > Language row, choose the language you want. The mod follows that choice for its spoken menu text, hints, prompts, and other announcements. You can change it during a session. The game's original text and audio remain under the game's own control.

Each language has a separate copy of this HTML guide in documentation\<language>\BopItAccess-user-guide.html. Opening the guide in the game loads the copy for the language currently selected in Settings. If that copy is missing or cannot be read, the English guide opens instead. The other project documents also have translated copies in the same language folders.

The included languages are English, French, Italian, German, Spanish (Spain), Spanish (Latin America), Japanese, Korean, Simplified Chinese, and Brazilian Portuguese. The first non-English translations are machine-generated drafts and welcome corrections from fluent speakers.

Gameplay action names follow the game's own translations so the five spoken commands stay distinct. The four stage titles—Shapes, Space, City, and Office—remain in English because they are displayed as fixed names in the game. The mod sends translated text to your selected speech output; that output also needs a voice for your language. For OneCore or SAPI, select a suitable installed voice in Mod Settings if the system default does not pronounce the translated text well.

Read the guide in game

Choose Read user's guide on the welcome screen or Open User's Guide in Mod Settings. The guide opens inside Bop It!, using the HTML file for your current game language in the game's documentation folder. Its topic list follows that document's table of contents, so updating the installed document updates the in-game topics and their text.

On the topic list, use the game's Up/Down menu controls to choose a topic and Confirm to open it. In a topic, use Up/Down to move through the text one line at a time. In a table, Left moves to the column on the left and Right moves to the column on the right. Up/Down moves between rows while keeping your current column. Column headings label the cells you hear; they are not extra data rows. The guide announces the table when you enter it and its end when you leave it, without repeating the table description for every cell. Confirm repeats the current line. Back returns from a topic to the topic list; Back again leaves the guide. The music uses the game's reading-friendly audio filter while the guide is open.

Mod Settings menu

Open Settings > Mod Settings. Move through the rows with your menu Up/Down control. Confirm a toggle or button; use Left/Right to change a slider. The defaults below are for a new setup. Changes are remembered between sessions. If speech is off, Toggle Speech still works, and the Speech Output row uses that same master switch. Voice, Volume, Rate, and Pitch adjust the OneCore or SAPI engine actually in use, even when Output Mode is Auto. Only supported controls appear; they are hidden for outputs without these adjustments. OneCore and SAPI keep separate voice and adjustment choices.

Editing the settings file

If a language, loud game audio, or a troublesome voice makes the menus difficult to use, you can change the settings outside the game. After startup, the mod automatically creates UserData/BopItAccess.ini inside your Bop It! game folder, using your current settings. This is a plain-text file you can open with an editor such as Notepad.

The file includes the game’s language, music, effects and voice-over volumes, vibration, full screen, resolution and audio latency; mod speech, braille, hint and other preferences; separate OneCore and SAPI voice profiles; and player-facing game and mod input bindings. Available resolutions and installed voices are listed in comments.

Close the game before editing. Find the relevant section and change the value of the existing entry, save the file, then launch the game again. Changes are read on launch, not immediately while the game is running. Changes made through the game’s menus update the file automatically.

Section and setting names stay in English in every language so they remain consistent. On and Off are the recommended toggle values; True/False, Yes/No and 1/0 are also accepted. The comments beside settings explain their choices and ranges. Missing entries and invalid values leave the corresponding saved setting unchanged; other valid edits still apply. Duplicate input assignments are rejected.

Comments and unknown entries are kept. If another program changes the file while the game is running, the mod stops saving to that file for the rest of the session to protect those edits. Close and reopen the game to use them. You can keep a backup before making changes.

For a voice problem, set Voice=System default in the OneCore or SAPI section. OneCore voice choices use name | language; SAPI accepts an installed voice’s displayed name or its full registry ID. The file lists available choices. OutputMode=Auto tries a running supported screen reader, then OneCore, then SAPI.

The example below restores English, quieter game audio and speech with automatic output and system-default voices. Change the matching entries already in your file; this is a reference excerpt, not an extra block to append. Leave your other settings in place.

[Game]
Language=en
MusicVolume=30
SfxVolume=30
VoiceOverVolume=30

[Mod]
SpeechOutput=On
OutputMode=Auto

[OneCore]
Voice=System default

[SAPI]
Voice=System default

Audio latency calibration

Audio latency is the delay between the game producing a sound and you hearing it. This screen helps the game account for that delay. Listen to its instructions, follow the warmup, and use Bop with the calibration beat. The mod announces the instructions, countdown, and measured result, but does not narrate each beat because that could hide the timing sound. After your final calibration input, the mod immediately says “Done!”; stop bopping and wait for the measured result. If calibration fails because no input was made, it says “Calibration failed.”

Detailed mode guide

All four modes begin by choosing a song/stage and choosing Classic or Extreme. The stage changes what you see and hear, while the commands tell you what input to make. Classic asks for Bop, Twist, and Pull. Extreme can also ask for Spin and Flick. When the game speaks a command, press its assigned input before the time window ends. You can review or change the assignments in Settings > Controls before playing. The tempo rises during a successful run, so there is no fixed last song section to reach. These rules come from the official game description and the game's current scoring and result screens.

Solo

Solo is the simplest place to learn the rhythm. One person responds to each spoken command. If the game says Bop, use your Bop input; if it says Twist or Pull, use that input instead. In Extreme, be ready for Spin and Flick too. Keep going as the commands become faster.

Scoring: Each correct response adds one point to the ongoing run. The score is your count of successful responses. A wrong or missed response, including one made too late, ends that run. The final result screen shows your numeric score. The mod announces it before reading Replay, Leaderboard, or Back. You can press Read Score to hear it again. Solo scores may also appear in Local, Friends, and Global leaderboard views when those views are available.

How to start over: Select Replay on the result screen, or return and choose another mode or song. A replay is a new run; your previous result can still be compared on the leaderboard where the game records it.

Party

Party is for a group taking turns. Each person plays their own run, responding to the same kinds of called commands as Solo. When a person's run ends, the game can ask for a name to attach to that score. Continue to the session's Party leaderboard, then let the next person take a turn. This is a friendly way to compare runs without having everybody act at once.

Scoring: Successful responses build that player's numeric run score. A wrong, missed, or late command ends their run, and the final score belongs to that player. The session leaderboard lists names, ranks, and scores so the group can compare results. The game does not impose a single formal winner; your group can decide what counts as winning. The mod reads the score at game over, then the next menu choice, and speaks the Party name and leaderboard steps.

How to keep playing: Use Continue when it is offered, choose or confirm the name if prompted, and follow the game to the next player or score view. If you replay, that begins another scored run rather than extending the one that just ended.

Pass It

Pass It is a shared challenge. One player responds to commands until the game calls Pass It! At that call, hand the controller to the next person promptly. The next player continues the same streak. Keep passing when told and keep answering the game's Bop It commands. This mode works best when everyone knows who receives the controller next and has enough space to pass it safely.

Scoring: Correct responses continue one shared numeric score rather than starting a new score for each person. The person who breaks the streak by missing a command ends the round. The result screen shows the final shared score, which the mod speaks automatically and can repeat with Read Score. The score tells you how far the group got; it is not an individual player ranking in this mode.

How to try again: Choose Replay to start a fresh shared streak, or Back to leave the results.

One-on-One

One-on-One puts two players, Yellow and Green, into the same round. Each begins with three lives. Yellow responds to Twist and Pull; Green responds to Spin and Flick. Bop is a shared race: both players should be ready, and the first to hit Bop gains a life, up to the game's three-life limit. The game provides subtle sounds for some changes. With Settings > Mod Settings > One-on-One Feedback on (the default), the mod announces the starting or changing active colour and the number of lives after a loss or gain. When a life is gained, the announcement identifies the player’s colour and new total. When a life is lost, it keeps the familiar count-only announcement.

How a round ends: Missing a required command costs the responsible player a life. The first player whose lives reach zero loses, and the other colour wins. Unlike Solo, Party, and Pass It, the result is a winner, not a numeric final score. The mod announces the winning colour at game over; Read Score repeats that result while the result screen is visible. The optional life announcements are for this mode only.

Getting ready together: Agree which person is Yellow and which is Green before starting. Check the current Controls screen, especially the second Bop assignment, if you will share one input device. One-on-One is fast, so a practice round can help both players learn their controls.

What may come next

This project is essentially complete, and no major content or features are planned.
