Welcome

Welcome to Bop It Access! Whether this is your first Bop It game, your first video game, or a game you already love, you are welcome here. This guide starts with the basics and explains the mod's features as you encounter them. You can use the contents above to jump straight to a topic.

A keyboard is the set of keys on your computer. A controller is a handheld gamepad. Where this guide mentions Xbox button names, they are examples: another controller may use different labels for the same button position. A menu item is a choice such as Play or Settings. The item with focus is the one your next confirm press will activate.

What is Bop It!?

Bop It! The Video Game brings the Bop It rhythm and reaction game to a computer. A voice calls commands, and you make the matching input before time runs out. In Classic difficulty the main commands are Bop, Twist, and Pull. Extreme difficulty also adds Spin and Flick. The commands get faster, so listening and timing matter more as a round goes on. The game offers Solo, Party, Pass It, and One-on-One play, with four visual and musical stages: Shapes, Space, City, and Office. The official Steam page introduces the game, and the official game description explains its modes.

When you hear a command, use its assigned control. For example, on the default keyboard, Bop is Space. You can find every default in the control reference. You do not have to memorize everything before starting: the mod can speak button hints on menus, and you can request a hint on demand.

What is Bop It Access?

Bop It Access is an unofficial, independent mod for the Windows x64 Steam version of the game. A mod is an optional addition that changes how a game behaves. This one adds speech and braille support for menus and results, on-demand descriptions of the four stages, extra controls, and useful settings such as a frame-rate limit. It aims to make the game easier to navigate while leaving its spoken gameplay cues and timing intact.

The mod uses MelonLoader to load into the game. It uses Tolk to communicate with supported screen readers and can use Windows SAPI speech as a fallback. It does not replace the game, and you still need your own copy of Bop It!.

Honest transparency note

This mod was made in heavy collaboration with artificial intelligence. All research for the mod was conducted by AI, and its code was generated by AI rather than originally written by hand. The design decisions and testing were entirely human. Every addition and change was carefully reviewed by a person, and real people played and tested the mod on different systems. Without agentic coding, this project would not exist. Thank you for giving this human-led, AI-assisted project a chance.

Accessibility features

  • Speech for the title screen, main menu, Play and song selection, Settings and Controls, speech settings, audio calibration, leaderboards, the in-game achievements book, credits, pause menu, and result screens.
  • Focused buttons, sliders, toggles, names, values, and changed values are announced. Optional indexing, control-type labels, slider ranges, and capitalization filtering let you tune the detail.
  • Score or winner speech at game over, followed by queued menu speech, plus a Read Score shortcut on the results screen only.
  • Four stage descriptions, spoken on request from the song-selection screen before play begins.
  • The game's tutorial text for the current mode and difficulty, spoken on request from song selection before play begins.
  • Optional One-on-One colour and life-count announcements.
  • Button hints for keyboard, controller, or both, with adjustable timing, repetitions, and an on-demand Speak Hints shortcut.
  • Screen-reader output through Tolk, optional braille output, and configurable SAPI fallback.
  • Keyboard and controller remapping for several native and mod controls, including leaderboard filters and speech shortcuts.
  • A saved master speech switch with spoken instructions for turning speech back on.

Quality of life features

  • A saved Limit FPS setting with 30, 60, 120, 240, and Unlimited options. The default is 60.
  • Separate options to mute game audio or mod speech when the game window is in the background.
  • A Change Speech Output shortcut that cycles through the same modes as the Speech menu.
  • Saved preferences across game sessions, including speech output, braille, hints, and the frame-rate cap.
  • More controls available for remapping in the game's own Controls menu, with duplicate assignments rejected.

Notes and limitations

  • Descriptions are requested before the round. The mod intentionally does not narrate scenery during active gameplay. A player must hear and react to the game's verbal commands; extra narration could cover a command and end the round.
  • SAPI is a backup speech engine. It is available when you prefer it or when no supported screen reader is running, but its responsiveness is still below the goal for this project. Your installed voice and system can affect the delay.
  • Some native controls are still fixed. The mod greatly expands the game's Controls menu, but it does not make every game input remappable.
  • Frame rate affects input polling. The FPS limiter can sharply reduce system load. It does not deliberately slow animations or change game timing, but the game checks frame-based input less often at lower FPS. A higher setting can give more accurate input timing, especially in fast rounds.
  • Speech support is strongest in menus and results. On an unexpected panel, the mod can read visible text and a focused control when it finds one. A mouse hover may not speak until that item actually receives game focus.
  • Windows x64 is the current mod platform. The game may be sold for other systems, but this mod's current loading and speech dependencies are for Windows x64.

Current installation route: build from source

The public GitHub repository currently contains source and documentation, with no compiled download or GitHub release. Building means turning the source files into the mod's DLL. The repository's build instructions are the maintained reference. Here is the complete current route in everyday language:

  1. Install the game through Steam on Windows x64. Find its folder from Steam's Library if you did not use the default location.
  2. With the game closed, install MelonLoader into that game folder. Development has used x64 MelonLoader 0.7.3 Open-Beta with this game; other combinations are not yet verified. Start the game once and close it again. This lets MelonLoader prepare the files the mod needs.
  3. Install a .NET SDK that includes the .NET 6 targeting pack. Download or clone the Bop It Access source, open PowerShell in the folder containing its README.md, and run the command below. Change the example game path if your Steam library is elsewhere.
$gameDir = 'C:\Program Files (x86)\Steam\steamapps\common\Bop It!'
dotnet build .\src\BopItAccess.csproj -c Release "-p:BopItGameDir=$gameDir"
  1. With the game closed, copy the built file src\bin\Release\net6.0\BopItAccess.dll into the game's Mods folder. Create that folder if needed.
  2. Obtain compatible 64-bit Tolk.dll and nvdaControllerClient64.dll from their upstream sources as described in the repository's installation instructions. Place both beside the game's executable, in the main game folder, not inside Mods.
  3. Start your screen reader if you use one, then launch the game through Steam. If there is no compatible running screen reader, the mod can use SAPI speech.

One common Steam location is C:\Program Files (x86)\Steam\steamapps\common\Bop It!. Your location may differ if you chose a different Steam library. If you have a locally supplied install ZIP from the project, close the game and extract its contents into the game folder, allowing the Mods folder to merge. Those local packages are separate from the source-only GitHub repository.

Your first launch

  1. Start your screen reader if you use one. Launch Bop It! through Steam after installing MelonLoader, the mod DLL, and the required Tolk runtime files.
  2. Wait for the announcement: Bop It Access speech is ready. The game is still loading. Wait for the title screen or main menu announcement before using the controls. The mod becomes ready before the game finishes loading.
  3. Wait several more seconds for the title screen or main menu announcement. Inputs may do nothing during loading. If you hear the title screen prompt, press Bop (Space by default, or your controller's confirm button) to open the main menu. Once a menu item such as Play is read, move with Up/Down and confirm with Enter, Space, or controller confirm.
  4. If you previously turned speech off, the saved setting stays off. The mod gives a spoken recovery message at startup with the current keyboard and controller binding for Toggle Speech. By default, press F8 or controller Select to turn it on again.
  5. For a comfortable first visit, open Settings > Speech and choose your speech, braille, and hint preferences. You can press H or right stick press for available button hints on a supported menu.

Detailed mode guide

All four modes begin by choosing a song/stage and choosing Classic or Extreme. The stage changes what you see and hear, while the commands tell you what input to make. Classic asks for Bop, Twist, and Pull. Extreme can also ask for Spin and Flick. When the game speaks a command, press its assigned input before the time window ends. You can review or change the assignments in Settings > Controls before playing. The tempo rises during a successful run, so there is no fixed last song section to reach. These rules come from the official game description and the game's current scoring and result screens.

Solo

Solo is the simplest place to learn the rhythm. One person responds to each spoken command. If the game says Bop, use your Bop input; if it says Twist or Pull, use that input instead. In Extreme, be ready for Spin and Flick too. Keep going as the commands become faster.

Scoring: Each correct response adds one point to the ongoing run. The score is your count of successful responses. A wrong or missed response, including one made too late, ends that run. The final result screen shows your numeric score. The mod announces it before reading Replay, Leaderboard, or Back. You can press Read Score to hear it again. Solo scores may also appear in Local, Friends, and Global leaderboard views when those views are available.

How to start over: Select Replay on the result screen, or return and choose another mode or song. A replay is a new run; your previous result can still be compared on the leaderboard where the game records it.

Party

Party is for a group taking turns. Each person plays their own run, responding to the same kinds of called commands as Solo. When a person's run ends, the game can ask for a name to attach to that score. Continue to the session's Party leaderboard, then let the next person take a turn. This is a friendly way to compare runs without having everybody act at once.

Scoring: Successful responses build that player's numeric run score. A wrong, missed, or late command ends their run, and the final score belongs to that player. The session leaderboard lists names, ranks, and scores so the group can compare results. The game does not impose a single formal winner; your group can decide what counts as winning. The mod reads the score at game over, then the next menu choice, and speaks the Party name and leaderboard steps.

How to keep playing: Use Continue when it is offered, choose or confirm the name if prompted, and follow the game to the next player or score view. If you replay, that begins another scored run rather than extending the one that just ended.

Pass It

Pass It is a shared challenge. One player responds to commands until the game calls Pass It! At that call, hand the controller to the next person promptly. The next player continues the same streak. Keep passing when told and keep answering the game's Bop It commands. This mode works best when everyone knows who receives the controller next and has enough space to pass it safely.

Scoring: Correct responses continue one shared numeric score rather than starting a new score for each person. The person who breaks the streak by missing a command ends the round. The result screen shows the final shared score, which the mod speaks automatically and can repeat with Read Score. The score tells you how far the group got; it is not an individual player ranking in this mode.

How to try again: Choose Replay to start a fresh shared streak, or Back to leave the results.

One-on-One

One-on-One puts two players, Yellow and Green, into the same round. Each begins with three lives. Yellow responds to Twist and Pull; Green responds to Spin and Flick. Bop is a shared race: both players should be ready, and the first to hit Bop gains a life, up to the game's three-life limit. The game provides subtle sounds for some changes. If you turn on Settings > Speech > One-on-One Feedback, the mod announces the starting or changing active colour and the number of lives after a loss or gain.

How a round ends: Missing a required command costs the responsible player a life. The first player whose lives reach zero loses, and the other colour wins. Unlike Solo, Party, and Pass It, the result is a winner, not a numeric final score. The mod announces the winning colour at game over; Read Score repeats that result while the result screen is visible. The optional life announcements are for this mode only.

Getting ready together: Agree which person is Yellow and which is Green before starting. Check the current Controls screen, especially the second Bop assignment, if you will share one input device. One-on-One is fast, so a practice round can help both players learn their controls.

What may come next

This project is still young. Potential work includes a proper installer and first-time welcome dialogue, stronger support for the remaining game screens, and continued improvements to speech responsiveness. We may explore switching speech handling from Tolk to Prism if it proves to be a better fit. That is an idea for research, not a current dependency or a promised switch.

Player suggestions and reports will help shape future improvements. Christopher intends to maintain the mod over time, with updates guided by real play and careful human review. The project repository is the place to follow its source and documentation as they develop.
